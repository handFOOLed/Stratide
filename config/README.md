# Configuration

[← 文档](../docs/README.md) · [使用指南](../docs/USER_GUIDE.md) · [Windows 安装](../docs/WINDOWS_INSTALL.md)

Stratide 的**运行配置和密钥保存在本机用户环境**，而不是 Git 仓库。

| 配置项 | 用户入口 |
| :--- | :--- |
| Tushare 数据源 | 设置 → 运行与安装 |
| DeepSeek 与预算 | 设置 → AI 服务 |
| TimesFM / WSL2 | 设置 → 运行与安装 |
| 模拟账户与风险 | 可信 Paper Ledger / 现有账户设置 |

默认数据位置 `%LOCALAPPDATA%\Stratide\data`，自定义路径以实际运行配置为准。**不要提交 API Key、Token、私有 SQLite、密钥或账户身份信息。**
