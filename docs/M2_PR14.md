## 只读与资源边界

必须显式传入 `--v1-root` 和 `--v2-root`。从原 schema 2012/2013 读取已准入版本，锁住两个现有 `writer.lock`，以 `mode=ro&immutable=1` 加 `query_only` 打开 SQLite。活动 writer、未恢复 WAL、异类 schema 和链接路径按原边界拒绝。没有迁移、备份数据库、重建索引或修改旧 manifest/checkpoint 的路径。

原主键索引支持按分区版本取数据；V1 再以 `(ts_code,trade_date,row_sha)` 精确连接。每次只装一个日期，SQLite 游标每批 1024 行，单分区最多 25000 行，历史窗口默认 61 个完成会话；最多 20000 个代码、1500 个会话、单进程/单线程、两个 8 MiB SQLite cache、512 MiB 实测峰值上限。每 100 会话输出处理数、耗时和峰值 RSS。新模块的 source 绑定校验仅检查小型契约/元数据/分区 manifest，不复算旧 raw 或数百万旧行哈希。

所有写入限定于当前 worktree 的 `state/multistock-research/<新实验>/`，已有目录拒绝覆盖。`inspect/plan/query` 离线只读；`report/verify` 只读新产物。源库只检查两个已知数据库和锁、WAL/SHM/journal 的尺寸/mtime 收据，不遍历全状态。完成后比较同一组收据；更关键的写入隔离来自原锁与 SQLite 只读连接。

## 冻结研究规则

Universe 每天从当日实际 V1 行开始，不从全期存活集合开始。策略子集要求沪深已确认会话、明确 A 股代码家族、连续 61 日可用行情/因子、上一完成日成交额至少 10000 千元且有成交量、无已知暂停或交易所冲突。缺日/NULL 因子清空该序列暖启动，不补行情。北交所、CDR/不可靠身份及其他类型单列，不能把子集绩效说成无偏全 A 股绩效。

| 标识 | 固定默认规则 |
| --- | --- |
| `momentum20_60` | 已完成 20/60 会话调整价格收益均值，正动量前 50，等权。 |
| `reversal5` | 已完成 5 会话收益最低前 50，等权。 |
| `inverse_vol20` | 20 会话样本波动率最低前 50，逆波动权重；波动下限 0.000001。 |
| `cash` | 不交易，现金收益/无风险利率均假设 0。 |
| `equal_weight` | 全部当日合格证券等权；不按最终收益挑代表证券。 |
| `sma20_60` | SMA20>SMA60 的证券按代码顺序最多 50 个，等权。 |

各规则每 5 个源会话生成目标。完成 t 的模拟开盘/收盘后才生成 t 收盘信号，最早于 t+1 的事后开盘价改变暴露。下一日 close、全天成交量及未来因子不参加 t 的特征或开盘决策。未来数据更新只影响其之后的特征/研究收益，不能改写已冻结输入。

采用从 1 开始的**无量纲调整价格暴露指数**，没有人民币初始资本、实际股份、订单、成交或账户 NAV。分数暴露未建模 100 股整手及最低佣金，不能把其净收益解释成可执行资金业绩。调仓先减少再增加，现金/暴露不为负，最大双边换手 200%；本会话新暴露不能在本会话卖出。停牌、缺行情/因子/限价、身份/交易所冲突和限价触及造成显式拒绝；其它开盘变更仍 `UNCERTIFIED`。日内深度、冲击容量与真实 T+1 结算没有认证。

| 成本情景 | 双向佣金 | 双向过户假设 | 双向滑点 | 卖出印花税假设 |
| --- | --- | --- | --- | --- |
| gross | 0 bp | 0 bp | 0 bp | 0 bp |
| base | 3 bp | 0.1 bp | 10 bp | 2023-08-28 前 10 bp，之后 5 bp |
| stress | 5 bp | 0.2 bp | 30 bp | 同 base |

这些比例是冻结研究模型，可通过配置调整，不宣称为每只证券每个历史订单的实际收费。收益为复权价格近似，未认证实际现金分红、税或总回报。持有证券缺估值时明确保留上次调整价格并标 `PARTIAL_STALE_MARK_ASSUMPTIONS`，报告 stale 会话/最高权重及期末“未定价暴露零回收”敏感性；既不虚构退市成交，也不把这种指数当完整可靠收益。

## 时间隔离与冻结文件

2021—2022 为开发段，2023 为验证段；2024/2025/2026 为预先固定、未用于参数/赢家选择的后期窗口。每个 Walk-forward 从归一化指数 1、空暴露重新开始，沿用其左侧历史特征；训练边界 purge 1 个信号会话，窗口首个源会话 embargo，下一源会话开始评测。规则无拟合/标签训练步骤，`purge=1` 记录的是 horizon=1 的隔离约定，不能把它包装为训练过且独立获证的模型。

全期结果、连续路径分段结果和重置后的 Walk-forward 分开保存。每个窗口均有 6×3 结果，包含含/不含成本收益、年化（252 会话）、样本波动、零利率 Sharpe、最大回撤、双边换手、拒绝数量及 stale 影响。全期同时给出对现金/等权/SMA 的收益差；窗口表亦可直接对照这三个基准。没有真实历史 PIT，后期时间隔离也不等于真实盲测或可晋级证据。

```text
state/multistock-research/<experiment>/
  plan.json          # 计算前：参数、窗口、source refs、版本界、query/code SHA、plan SHA
  frozen-source/     # 本次实际使用的五个 Python 源文件
  signals.jsonl      # 信号日、最早下一会话、目标数量/SHA
  daily.jsonl        # 全期/Walk-forward 无量纲路径、成本、拒绝、stale
  results.json       # 冻结汇总
  execution.json     # 实际取得时间、耗时、CPU、峰值内存和只读收据
  run.json           # 输出文件散列；确定性 output SHA 与单次 execution SHA 分开
```

后续数据修订产生新 source/plan SHA；原版本上界和旧报告保持不变。`verify` 仅验证这一份新研究文件及冻结代码，不触发 PR58/60 的全量 `verify`。中断会写 `interrupted.json`，列实际完成日期/数量与原冻结计划；恢复方式是保留旧证据，以同版本和配置在新输出目录重跑，不隐式刷新数据。

## CLI

Python 3.12 标准库即可，以下从独立 worktree 根运行。先使用本机现存库的目录替换两个 locator，Token 不需要配置。

```powershell
python -I -B scripts/multistock-research.py inspect --v1-root '<V1_ROOT>' --v2-root '<V2_ROOT>'
python -I -B scripts/multistock-research.py plan --v1-root '<V1_ROOT>' --v2-root '<V2_ROOT>' --v1-version 1212 --v2-version 4848

python -I -B scripts/multistock-research.py query --v1-root '<V1_ROOT>' --v2-root '<V2_ROOT>' --date 20211101 --symbols 600000.SH,000001.SZ,600519.SH --limit 3

python -I -B scripts/multistock-research.py run --v1-root '<V1_ROOT>' --v2-root '<V2_ROOT>' --v1-version 1212 --v2-version 4848 --out state/multistock-research/<new-experiment>
python -I -B scripts/multistock-research.py report --out state/multistock-research/<experiment>
python -I -B scripts/multistock-research.py verify --out state/multistock-research/<experiment>
python -I -B scripts/test-multistock-research.py
```

`report --full` 展示完整研究汇总。`--config <json>` 仅覆盖显式支持的研究参数/成本/窗口；改参数即新实验，不覆盖旧结果。短期源范围需明确给出其开发/验证/评价窗口，不能把默认五年窗口暗中裁成“通过”。复制 `plan.json` 的 `config` 字段为本地配置，固定两个版本上界并使用归档的同版源代码，即可复现；本期不为重复证明而再次全量读取真实旧库。
