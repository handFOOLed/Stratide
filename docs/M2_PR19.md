## 接线与边界

费用、凭据和重复派发按 P0；来源与研究组合正确性按 P1。旧 BigQuery/recorded、PR17 结构化研究、PR18 CPU、原 Frozen adapter SHA 与 Risk/Execution 均保留。

```text
原 TimesFM preflight → enable → synthetic-freeze → once → verify
  → 原 AgentDir/tasks：local-timesfm-2.5-cpu / LOCAL_NO_BILLING / calls=0
  → local_timesfm_fusion_v1：父任务 ID + 结果存储 SHA + Plan SHA + Owner 绑定
  → 原 Rust Agent → 原 Budget reserve/check_dispatch → PR17 HTTPS client
  → 原 TargetPortfolioProposal V1 严格校验 → 原 Registry/Inbox/report/verify
```

新桥读取原数据库中的 completed 本地任务，由 Rust 从保存的 Worker response 重建 RiskExpertResult，核对 Frozen/as_of/会话、模型/权重/manifest、provider hash、结果 SHA 和 `development_only=false`。失败、取消、不完整、跨 AgentDir 或来源变化不能进入付费调用。没有第二套 Python 付费 HTTP。

内部默认别名是 `ds4.1flash`；Fusion 路由 ID 为 `ds4.1flash-fusion`，以便与 PR17 的不同目的授权并存，实际 API model 都是 `deepseek-flash`。同一真实 Agent 默认选择 `ds4.1flash`。Fusion 必须有独立 `portfolio_fusion_v1` grant，旧 `cloud_structured_research_v1` grant 不够。PR17 仍需原配置/启用控件。

本期只允许 `synthetic_test`：外发合成证券标识、5/20 会话 rolling20 RMS、Naive/EWMA、regime、UNKNOWN/质量限制、来源 SHA 和 V1 JSON 契约。原始时间序列、Tushare 数据、账户、持仓、成交、未来标签、路径及凭据不进入请求。回包严格校验整数 bps、现金与持仓合计 10000、来源一致性和证据池证券。100% 现金合法，未验证发现不能直接持仓。Paper/Live 始终 BLOCKED。

## 唯一真实 CNY 费用权威

发现的旧库均为 TST；按原 `Agent::open` 流程初始化唯一独立 CNY 实例并固定 Owner 绑定。旧 TST 历史没有换币种或重置。所有 worktree 经 Git common root 的同一绑定读取同一 AgentDir/settings/agent.sqlite，没有 Fusion 专用钱包。

```json
"budget": {
  "currency": "CNY",
  "timezone": "Asia/Shanghai",
  "daily_limit_micro": 5000000,
  "monthly_limit_micro": 100000000
}
```

这是整个真实 Agent 的合计限额，PR17、Fusion 及以后挂在同一 Agent 的付费调用共用原 calls 表。原 reserve/check_dispatch 保持不变，历史未知预留跨日/月继续占用两个周期额度。cap 未配置、已用加预留达到 cap、撤销或停止时不能开始新付费调用。

2026-11-03 复核的[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：Flash 高峰输入缓存未命中 ¥2/百万 token、输出 ¥8/百万 token。忽略空闲与缓存优惠，32768 输入 + 4096 输出的保守预留为 **98304 micro CNY = ¥0.098304**。配置价格有效期最长 7 天，过期需更新本机价格配置并重新冻结。

usage 仅为估算；原账本保留最大预留，直到 Owner 经原发票核销入口确认。429/500、超时、断开、缺 usage、非法组合都不自动重试，未知费用不自动释放。本地 cap 不能控制同一 DeepSeek 账户其他客户端的消费。

## 响应审计与当前限制

真实首验发生在诊断补丁前：原实现只保留响应 SHA 和用量，没有保留具体响应，因此不能离线确定究竟缺少/多出哪个字段，不能修复原回包或补记 Provider request ID。

最终实现明确提示精确根字段/类型，并在成功 HTTP 回应且无凭据回显时，将有界响应保存到 ignored 本机私有 `local-fusion-wire.json`（Unix 0600、最多 64 KiB、create_new、不覆盖）。HTTP 错误 body 丢弃，Key 回显不落盘。保存的响应只用于离线诊断与 SHA 校验，不自动重发、修补权重或制造成功。verify 读取原任务/真实字节并重建组合，不推理、不恢复任务、不读取 Key、不计费。源码变化后 status 仍显示原保存上下文，新 adapter 不替旧结果签名。

合成 loopback 已通过 Registry/Inbox/report/verify；真实首验没有合法组合，所以没有真实成功归档。N100 真机性能、真实市场数据、预测 alpha、Paper/Live 资格没有新增验证。
