# ADR-012：有每日硬上限的自主研究预算

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- Owner 选择：**B，自适应研究预算规划，但保留每天的用户设定硬上限**
- 决策范围：Agent 的研究、实验与相关模型/API/按量计算成本；不是交易账户的本金/风险预算（见 ADR-008）
- 待决定：具体每日金额、货币与报价来源、重置时区、预付数据订阅是否计入、预估计费误差容忍与第三方账单对账方式

## 目标

允许研究 Agent 根据候选课题的预期信息增益、实际实验价值与剩余额度，自主规划当天的研究任务，不为每个研究实验请求人工批准。但 Owner 的每日研究支出上限不可由 Agent 自行提高，也不得通过启动多项并行/跨日实验规避。

## 决策

1. **由 Owner 设定 `research.daily_spend_limit`**：未设定有效每日上限时，禁止启动会产生计费的自主研究任务。具体数值必须由 Owner 以后明确配置；不能从账户本金、10 万元的示例规模或交易利润推导。
2. **Agent 自主分配预算**：可选择优先实验、决定每次研究的模型/数据/远程算力预算、推迟低价值任务，尽量将可用额度用于能验证/证伪假设的实验；不得写入或修改 Owner 的硬上限，也不得自动充值、购买订阅或扩大第三方配额。
3. **限额执行归受信任的 Budget Gate 管理**，而非提示词或 Agent 自报：调用付费 LLM、云实验或其他按量计费研究服务前，必须检查当日已确认消耗、正在运行任务预留额度以及本次任务的保守最大预估费用；预算不足则拒绝新任务，不以“预计之后可赚回来”破例。
4. **并行与跨日预留**：多项同时执行的任务共享同一每日预算账本，不得重复使用剩余额度；无法给出合理成本上界的任务不能作为完全无人值守的付费任务运行。跨日和任务取消需按实际账单/保留额结算，不能通过重新启动服务重置已消耗额度。
5. **第三方计费限制**：模型提供方、云资源及数据服务可能延迟上报用量或存在最小计费单位，应用内的预算闸门无法保证外部最终账单绝不超出精确金额。使用保守预留、供应商侧费用上限/报警（若支持）、账单核对和费用缓冲来降低超额风险，并明确向 Owner 报告估计与实收差异。
6. **预算用尽后**：暂停新的**付费研究**，允许不产生额外费用的结果整理与待续任务规划；不得影响本地 Risk Kernel、已有持仓/订单管理或账户对账。生产运行如需额外付费服务，其**关键运行预算和服务降级规则必须单独配置**，绝不能默默从研究预算借款、也不能为节约研究费跳过风险检查。
7. **每日重置配置**：按 Owner 指定时区/自然日定义每日额度，保证重启与跨平台部署一致；具体时区在实际配置中明确记录，不凭空假定当前系统时区。前一天未用余额默认不积转为下一天额外授权，除非 Owner 另行批准该能力。
8. **低开销可观测性**：记录研究任务费用预估/预留/实际、模型与计算来源、成果/失败、当天剩余预算，在低打扰日报中简要汇报；不必先构建完整 FinOps 平台或优化器。
9. **与其他决策关系**：研究费用上限不等于 ADR-008 中的研究本金上限，也不等于实际交易账户风险预算。Agent 获得研究任务选择权，不获得提高资金或实盘风险权限的权力。
10. **M0 边界**：当前 paper-only 骨架无需接付费 Agent 或实施真实 API 计费。未来新增研究 Agent 时先做单机轻量 Budget Gate 与可追踪的额度账本，再按实际供应商补充额度控制。

## 财务风险相关验收（实施时）

- 每日剩余额度不足以覆盖保守预留成本时，拒绝新付费任务；若多个任务同时申请预算，只能在同一限额中独占预留。
- Agent、策略代码或远程 Worker 无法修改每日上限或借用交易账户本金支付研究费。
- 同一日内重启程序不会清空账本；次日重置遵守 Owner 的时区与日期。
- 第三方费用不确定、结算滞后时，报告预估与实收差异，不能承诺不存在任何超额收费。
- 达到研究日限额，交易风控、对账和已运行策略不会因为研究预算用尽而直接失效。
