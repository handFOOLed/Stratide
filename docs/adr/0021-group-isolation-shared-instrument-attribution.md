# ADR-021：多策略组共用标的、独立数据归属与统一账户清算

- 状态：已接受（Accepted）
- 日期：2026-10-27
- Owner 选择：B。不同策略组可交易同一标的；每组生成的数据、信号、持仓和盈亏归属应当隔离，不能互相污染。
- 关联：ADR-008 共享资金池、ADR-019 双层风控、ADR-020 新版本准入、ADR-002 可信订单网关。
- 尚待设计：跨组内部虚拟权益转移的参考价具体行情字段与部分成交归属、组级权限的具体存储结构、跨组共享风险的最简暴露指标。可信组合层进行跨组净额处理的方向已由 [ADR-022](0022-trusted-cross-group-intent-netting.md) 确定。

组间检索、索引授权与策略摘要返回需遵循 [ADR-026](0026-budgeted-shadow-observation-and-local-strategy-registry.md)，不能因为有全局策略注册表就开放其他组私有数据。

当 Owner 人工接管后实际成交使总持仓与组级历史份额不符时，不得自动按比例扣组别份额；先在可信待归属账簿记录差异并停用受影响的旧库存，参见 [ADR-032](0032-manual-trades-suspense-ledger-unassigned-attribution.md)。

## 核心模型

- `group_id` 是策略组的数据与运行归属边界；`family_id` 表示研究血缘，两者不自动等同。
- `artifact_hash` 标识冻结版本，`deployment_id` 标识具体执行实例；策略组内可有多个版本或运行实例。
- 各组维护自身的策略信号、研究实验、模型/特征、内部状态、虚拟份额、策略绩效、调拨与费用归属。数据读写默认按 `group_id` 分区；组 A 不能随意读取或覆盖组 B 的内部数据，除非 Owner 另行授权明确的跨组研究。
- 共享的基础公开行情和公共市场事件可以由 Data Manager 统一提供，避免无意义地复制；这不代表可以共享其他组的私有因子和实验结果。

## 已确认决策

1. **允许同标的多组参与。** 组 A 和组 B 都可以研究和持有同一只股票；不因存在另一组而禁止某组产生信号。
2. **真实资产只有一份。** 券商只看到一个真实账户的实际现金、仓位、待成交订单和成交结果。可信 Portfolio / Risk / Execution 负责在共享账本里合并、净额处理及核算，任何组的内部份额都不能额外创造真实资产或豁免账户限额。
3. **组内独立归因。** 每项提案、虚拟持仓份额、资金预算占用、买卖指令、成交映射、费用、已实现和未实现盈亏，必须有可审计的策略组和具体策略版本/部署关联。发生再平衡、移交或净额交易时，不得把内部资金转移伪造成策略利润。
4. **组间数据隔离。** 组 A 的内部研究结果、私有特征、信号、模拟净值、模型输入输出与策略记忆，不得隐式成为组 B 的输入，也不得被组 B 更改。Agent 若跨组汇总，仅允许读取经过可信聚合的账户级指标或 Owner 明确授权的可分享摘要。
5. **统一风险约束始终有效。** 账户级权益、总敞口、流动性、单票集中度、整体相关性、熔断与券商状态仍必须考虑所有组的实际贡献；这种全局约束可能让某组无法增仓，但不等于泄露另一组的私有研究数据。各组的亏损限制按本组归属执行，并服从 ADR-019 的账户最高优先级。
6. **相反信号不代表自动完成真实交易。** 同标的组 A 买入、组 B 卖出时，可信组合管理可以考虑抵消外部订单以减少摩擦；但内部持仓权益转移、结算价格、成本与交易限制必须有可信规则与审计记录。不得虚构券商成交、错误确认交割、制造无法兑现的纸面利润，或绕过 A 股 T+1 等实际可交易限制。[ADR-022](0022-trusted-cross-group-intent-netting.md) 已确定，由可信组合分配器在执行前统一净额处理；内部双方统一参考价的原则已由 [ADR-023](0023-single-market-reference-internal-transfer.md) 确定；具体行情字段和分摊细节仍待确定。
7. **生命周期隔离。** 某组亏损冻结或版本替换，不应直接改写别组研究数据、历史持仓归因与局部风险状态；但真实账户已有敞口、订单不确定性和账户级熔断必须统一反映。Owner 禁令及新版本准入规则遵循 ADR-009/020。
8. **实现范围克制。** M0 保持单组单策略模拟闭环，订单/归因事件契约预留 `group_id`、版本和部署关联字段；到真正多组运行时再实现分组视图、内部净额结算和交叉持仓归因，避免提前搭建庞大资金归因平台。

## 未来验收

- 组 A/B 持有同一证券时，组级持仓份额之和与真实账本一致；总资金、费用与敞口不重复计算。
- 组 A 的研究文件、私有信号及策略运行数据不会无授权影响组 B 的信号或被组 B 写入。
- 组 A 冻结仅阻止 A 新增风险；账户级熔断可同时阻止 A、B 增加风险。
- 对冲方向的内部净额不可制造不存在的真实成交，账户现金/证券余额仍可对账。
- 对各策略组的绩效、订单和成本能够追溯，不以内部调拨制造盈利记录。

> 设计已确认；当前 M0 尚未实现多策略组独立归因或真实交易。
