# ADR-007：按策略频率选择保守成交模拟精度

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- 适用范围：研究/回测/前向模拟中的订单可执行性与成交假设
- 暂未决定：券商、具体品种规则、成交/滑点参数、未来盘口级数据来源

## 背景

高收益回测可能建立在无法实现的成交上：涨跌停或停牌期间仍“成交”、信号出现后立即用同一根 K 线收盘价买入、忽略交易费、T+1 或交易单位限制。另一方面，逐笔盘口和排队模型成本高昂，未必能显著改善初期日频策略的评估质量。

Owner 选择 **A：与策略频率匹配的保守模拟** 为初期默认方案。保留未来针对真实高频/盘口策略使用更高精度数据的能力，不把日频模拟器变成研究方向上限。

## 决策

1. **第一阶段采用轻量日频模拟器。** 用日线市场数据和明确、偏保守的成交假设；不能将触及价格等同于“确定能成交”，也不能编造日线数据无法证实的逐笔行为。
2. **按品种和交易日启用实际适用规则。** 模拟器需要根据证券类型/板块/日期考虑交易单位、T+1 可卖性（适用时）、涨跌幅限制（适用时）、停复牌、手续费/税费、价格单位以及必要的流动性限制。不要把 A 股股票的规则未经核实套用到所有 ETF 或其他资产。
3. **避免时间穿越。** 决策只能使用当时可得数据；基于某日完整收盘数据做出的信号，默认不得在同一收盘时刻按已知价格成交。信号与后续可执行时点必须分离；如需不同执行假设，要证明数据足以支持。
4. **明确不确定性和成本。** 如果只有 OHLCV 无法确认限价单是否成交、日内止损先后顺序或盘口队列优先级，保守处理或标记“无法可靠模拟”，不得以最有利情况补全。手续费、滑点和执行失败应反映在**净收益**里。
5. **精度随策略需求升级。** 如果候选研究方向依赖分钟/逐笔、盘口深度、竞价队列或延迟，必须先获得能够支撑结论的适当数据及执行模型，再用于正式验证；研究仍可探索，但简单日线回测**不能为此类策略提供实盘晋升依据**。
6. **不做大而全微观结构系统。** M0 只实现一个可重放、数据/费用来源可解释的纸面交易最小纵切，重点覆盖真正影响金额或可成交性的规则；不为不存在的券商和品种构建完整市场仿真器。

## 与 ADR-005 / ADR-006 的关系

- 数据可信度分级（ADR-005）决定历史信息在何时可得。
- 独立验证隔离（ADR-006）决定谁能将模拟结果认定为晋升证据。
- 本 ADR 规定模拟器不能通过不真实的成交假设制造看似盈利的策略；任何单一回测仍然不是实盘许可。

## 有价值的后续测试场景

- 根据收盘数据产生的信号不能以同一收盘价无条件回填成交。
- 停牌、适用涨跌停无法成交、已买未达可卖时点等情形不能凭空完成交易。
- 回测权益与净收益必须包含适用品种的手续费/税费/滑点。
- 无法确定成交的订单不能默认按对策略最有利的路径完成。

> 本 ADR 为架构与评估规则。当前 M0 工程骨架尚未实现上述模拟功能。
