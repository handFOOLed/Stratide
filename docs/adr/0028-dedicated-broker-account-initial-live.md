# ADR-028：首个实盘版本使用 Stratide 专用证券账户

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- Owner 选择：**A — Stratide 首次接入真实券商时使用专用证券账户，不与日常人工交易混用**
- 关联：[ADR-003](0003-account-wide-order-uncertainty.md) 券商状态不确定冻结、[ADR-004](0004-configurable-conditional-recovery.md) 技术恢复、[ADR-008](0008-dynamic-portfolio-capital-cap.md) 唯一账户真实资金池、[ADR-017](0017-single-writer-durable-recovery.md) 单一执行主体与对账、[ADR-019](0019-account-and-strategy-risk-layers.md) 账户/策略双层风险、[ADR-021](0021-group-isolation-shared-instrument-attribution.md) 虚拟组级归属。
- 待决：具体支持的券商/账户类型及是否允许开立独立账户；Owner 临时紧急接管/人工操作流程；实际券商订单/成交/资金/持仓对账接口、时间窗口与异常恢复细节。没有券商条件验证不声称可开立额外账户。

## 背景

Stratide 可以管理多策略组，但它们共享唯一的真实券商账户资金和证券持仓。若 Owner 同时在券商 App 人工买卖同一账户，策略虚拟归属、可卖数量、预算与账本可能瞬间失真。首个实盘版本优先减少资金归属与订单来源复杂度，而不是承诺自动适配任意人工交易。

## 决策

1. **专用真实账户、单一策略系统管理范围。** 首次真实资金部署前，Owner 需指定一个仅供 Stratide 运营的真实券商账户，与日常人工证券投资账户分离。该账户内多个策略组仍共享账户唯一的实际现金、持仓和总风险，不为每组开立独立真实证券账户。
2. **常规期间不混入人工交易。** Stratide 正在拥有真实执行权时，Owner 不把该专用账户用于日常券商 App 交易，不让其他自动交易工具或第二台机器独立提交订单；不假设此约定在券商层面可技术性锁死。账户出入金、红利到账、配股及公司行为可能合法改变账面记录，必须作为可审计的特殊事件处理，不得混同投资收益。
3. **专户不等于无需对账。** 启动、执行状态不确定、恢复、券商回报缺失、关键持仓/余额变化等场景，必须依据实际券商支持的权威数据核对订单、成交、证券数量、可卖数量、现金与已冻结金额。帐簿只记录已确认事实，不凭“这个账户只有我在交易”的假设认定系统永远正确。
4. **不明外部交易或资产差异采取保守处理。** 发现未归属任何已知 Stratide 订单的成交、无法解释的持仓/现金变动、疑似人工订单或其他执行主体时，标记异常并阻止受影响真实账户**所有新增风险**。先读取权威券商历史并区分合法结算/公司行为/入出金/手续费等，再采用可信人工或条件恢复流程；不能把不明持仓自动分配给表现最好的策略、虚构历史订单或直接清空限制。
5. **单写入者原则继续有效。** ADR-017 的唯一可信下单主体、持久化和重启核对不因专用账户选择而减弱。Owner 禁令、账户级熔断和券商不确定性优先于任何自动策略晋升、预算扩张或内部组间净额（ADR-019/021/022）。
6. **紧急人工介入是例外。** Owner 直接在券商 App 紧急处理时，不意味着允许长期混合交易；依据 [ADR-029](0029-owner-manual-takeover-explicit-return.md)，Stratide 必须持久禁止新的自动券商提交，继续必要对账，且只有 Owner 经认证明确交还执行权并完成权威核验后才可恢复。既有挂单在接管确认时由 Owner 显式选择保留或尝试撤单，见 [ADR-030](0030-owner-takeover-pending-order-choice.md)；不能假设自动停机或发出撤单请求即已经撤单成功。
7. **券商能力须验证。** 是否能够合法开设及维护专用证券账户、券商 API 是否提供足够的订单/成交/余额/持仓查询、终端并发登录与访问许可，在真正选择券商时逐项核实。若专户或必要对账能力不可用，**首个实盘准入保持关闭**，需由 Owner 明确重新评估方案，不自动偷偷改成共享人工账户。
8. **M0 不引入真实账户功能。** 当前只有单组 paper-only 起步目标；不开发券商账户选择页、人工交易归因引擎、实盘交易或外部账户自动识别。后续实盘准备阶段再实施轻量真实账户绑定与对账及明确的紧急接管操作。

## 未来验收

- 日常股票买卖发生在 Owner 其他人工账户，不影响 Stratide 专用账户的策略归属；策略组仍共享其专用真实账户而不能重复算现金或证券。
- Stratide 运行中出现一笔无法映射到已知委托的券商成交，冻结整个专用账户新增风险并保留异常证据，不能继续假设账户可用余额未变。
- 配股、现金分红、手续费调整与入出金可以区分并审计，不被错误归入策略历史盈利；确有差异则先核实再恢复。
- 专用账户程序重启、订单超时、重复回报与执行权迁移仍遵守已有持久化、幂等和对账原则。
- 没有已核实券商开户/接口能力或未得到首次实盘授权，不可能仅凭本文档触发真实委托。

> ADR-028 为未来首个实盘版本的账户边界决定；当前 Stratide 仍为 M0 scaffold，不具备券商交易或对账能力。
