# ADR-006：独立验证隔离与避免多次试验造成的虚假优势

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- 决策范围：自主策略搜索与独立历史/前向验证的权限边界
- 暂未决定：具体留出区间、统计检验、测试额度、前向模拟时长及实盘准入数值

历史失败并不自动永久禁止再次研究；但新假设或改参必须保留此前试验记录，重用已有失败证据并重新接受独立验证，不得通过复测污染样本外证据。见 [ADR-027](0027-historical-failure-as-evidence-not-permanent-ban.md)。

## 问题

当 Agent 可以生成成千上万条策略并反复查询历史表现时，所谓“样本外”数据一旦被用来指导下一次策略修改，就不再是真正独立的检验。即使不存在真实交易优势，也可能仅凭多重尝试找到极高的偶然历史收益。

Owner 选择方案 **B：独立验证隔离**。保留无限制策略方向探索，同时避免研究反馈污染最终验证证据。

## 决策

1. **Research 与 Independent Evaluator 分权**。Agent 可以自由查看训练/探索数据、建立假设、编写及运行策略，但不能修改独立验证规则、私自读取保留验证数据的答案，或声明自己的试验“正式通过”。
2. **候选冻结后提交。** 进入独立评估前，记录不可变的策略代码/模型产物哈希、参数、数据版本、提交时间、已知研究历史和成本假设。Evaluator 以冻结版本测评；测后改参、改规则视为**新候选**。
3. **保留验证集使用有界且可审计。** 不把同一份保留区间无限当作调参反馈。记录正式评估尝试、候选关联关系和所用数据区间；返回足够判断是否值得前进的有限诊断，不无限暴露逐样本答案以供后续优化。
4. **结果不等于资格。** 单次历史高收益或过了某一分数不构成可部署优势；独立评估需要计入交易费用、冲击/滑点、流动性、可执行性和与简单基准的比较。多次选择带来的偶然性必须在后续决策中考虑。
5. **前向观察是关键补充。** 通过独立历史评估的候选仍需冻结版本并进入有时间记录的前向影子/模拟观察，以获得研究期未见过的数据。若保留数据被反复窥探或充分利用，其独立证据效力会降低，需使用之后新到的数据或新的可信保留样本。
6. **允许 No-Edge。** 没有可信证据时不上线新策略，不以“找到了最高回测收益”替代验证。
7. **保持轻量。** 当前只锁定权限边界、不可变候选记录、试验历史与前向观察要求；**不在 M0** 引入昂贵实验管理平台、几十项强制统计检验或拍脑袋设定硬性测试次数。
8. 本 ADR 仅约束独立验证证据。具体**策略如何被允许进入实盘及是否自动晋升**，是另一个待决策的权限问题，不能从“通过 Evaluator”直接推出“可下真单”。

## 财务风险相关验收方向（后续阶段）

- Agent 调参后不能继续冒用旧候选的独立验证结论。
- 同一保留区间被多次用于选择时，评估记录可追踪，不能隐瞒试验次数。
- 研究/独立评估数据与 ADR-005 的可信度级别配合：探索性历史表现不得冒充可晋升证据。
- 未通过独立检验或缺少可靠前向观察的策略不可获得真实资金权限。

**未实现声明：** 以上为架构协议，当前 Stratide M0 骨架没有 Evaluator 或自动策略晋升能力。
