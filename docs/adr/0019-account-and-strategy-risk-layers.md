# ADR-019：账户与策略双层财务风险控制

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- Owner 选择：**方案 B — 账户级与策略级双层风控**
- 决策范围：多策略组合的风险预算、独立策略亏损/回撤监控、局部冻结与全账户冻结之间的优先级
- 关联：[ADR-002](0002-in-process-risk-gateway.md) 强制风险网关、[ADR-008](0008-dynamic-portfolio-capital-cap.md) 单一共享资金池、[ADR-009](0009-auto-promotion-owner-veto.md) 自主晋升与用户否决、[ADR-018](0018-equity-based-loss-drawdown-breakers.md) 账户净值与资金流调整后的财务熔断
- 待决：各策略风险预算分配算法、相应亏损/回撤限额的数值、新版本重新准入见 [ADR-020](0020-versioned-requalification-auto-promotion.md)、复杂内部净额成交的收益/费用归属规则

## 背景

如果几套策略共享账户，某套策略可能连续亏损，其他策略却足以掩盖账户总体浮亏。只计算账户层面的风险会允许问题策略继续消耗组合的风险预算。Owner 选择在账户总风险约束之外增加**独立策略层面的风险约束**，但不要求用户逐个手动配置。

## 决策

1. **双层、同时生效，不可互相替代。** 任何新的交易提案都必须通过（a）所属策略级风险预算与有效资格、（b）账户级总风险敞口与财务熔断、（c）订单和交易规则等独立检查。策略未超限不代表账户可增仓；账户尚未触发熔断不代表亏损策略可继续增仓。全部由受信任 Risk Kernel 强制执行。
2. **动态但有总量边界。** Portfolio Allocator 可对通过独立验证的策略建议和调整目标资金/风险预算，允许对风险恶化的策略分配 0，具体双向扩缩容、衰退证据和高风险代码质量门槛由 [ADR-025](0025-adaptive-risk-budget-decay-quality-gates.md) 确定。Agent 不能扩张 Owner 设定的账户总本金、敞口、亏损/回撤阈值，也不能让策略预算的合计或实际组合订单风险超过同一共享账户的限制。预算分配仍须受 Risk Kernel 验证，防止并发订单重复预占额度。
3. **策略亏损包括浮亏。** 策略级监控应反映可信归属的已实现与未实现损益、分摊交易费用、可归属净值变化及回撤。策略之间真实共享的同一现金/持仓不能凭空重复计入各自资产；记录策略订单/成交、费用、分配和内部调拨归属，资金跨策略重新分配不应伪装成投资回报。具体估值/归属方法与复杂交叉持仓处理待实现时确定。
4. **策略级熔断的影响范围为局部。** 某策略超过其已配置损失/回撤限制或预算时，持久化该策略/受监管策略身份的冻结，立即拒绝**该策略新增风险**；未受影响且独立风险检查全部通过的其他策略可继续交易。已有仓位与订单通过可信对账和市场规则安全处理，不等于立即保证清仓。共享仓位若缺乏可靠的策略归属，应先停止相关不确定的新风险。
5. **账户级熔断优先且覆盖所有策略。** 整体账户触发 ADR-018 的亏损/回撤规则，或者发生 ADR-003 的券商未知订单状态，则整个账户停止新增风险。无论策略分数如何、是否使用不同标的、是否更换新版本，都不能以策略级“未超限”解除账户锁。
6. **反规避与状态持久化。** 账户/策略亏损、风险预算使用量、停机原因、策略身份和相关版本/家族证据应在可信账本保存；Agent 不得通过重命名、复制策略、分裂策略身份、重置回测窗口或重新部署相同逻辑来清空损失/锁定。对实质上新策略的识别和复核可依据冻结工件与独立 Evaluator 的策略血缘记录，不假装所有语义相同的策略都能仅凭哈希自动识别。
7. **恢复权限分离。** 技术故障自动恢复规则 ADR-004 不得清除策略或账户的财务风险熔断。旧版本财务限制保留，而新版本可按 [ADR-020](0020-versioned-requalification-auto-promotion.md) 完成独立评估与前向观察后自主晋升，不自动清除旧版本亏损、账户级熔断或有效 Owner 禁令。多组同标的、独立数据归属见 [ADR-021](0021-group-isolation-shared-instrument-attribution.md)。
8. **分阶段实施。** M0 仍是单策略 paper-only 垂直闭环，只需预留策略 ID / 可归属的交易记录字段及账户总量约束，设计一个代表性的策略拒绝/账户拒绝测试；没有必要此刻建设多策略资金归因引擎、协方差优化器或跨策略对冲会计。

## 财务风险验收（未来多策略阶段）

- A 策略触发局部亏损锁，B 策略仍可在自身与账户边界内新增风险；A 无法借 B 的预算直接开仓。
- 账户级亏损锁或未知券商订单触发后，A、B、C 所有策略都不能增加账户风险。
- 同一现金/持仓与未完成订单的风险占用不能被两个策略重复使用，策略资金调拨不制造虚假利润或新增授权本金。
- Agent 修改策略名称、版本或账户风险配置的提案，不能清除已有亏损锁或扩大交易权限。
- 估值/持仓归属重大不确定时不能凭空得出某策略“完全安全”而允许无约束新增风险。
- 策略级与账户级财务锁均在重启后持久有效，直到被另行规定的可信流程明确处理。

> 此 ADR 是多策略阶段的设计决定。当前 Stratide 仍为 M0 工程骨架，无真实多策略组合风控或券商执行能力。
