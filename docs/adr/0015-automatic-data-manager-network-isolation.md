# ADR-015：自动数据源管理与生产策略 Worker 网络隔离

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- Owner 决策：方案 **A**；数据源的发现/管理尽可能自动化，不要求 Owner 手动维护清单
- 关联：[ADR-005](0005-tiered-data-evidence.md) 时间可得性与证据分级、[ADR-012](0012-adaptive-research-daily-hard-budget.md) 付费研究日预算、[ADR-013](0013-one-time-cloud-data-consent.md) 一次性持久授权、[ADR-014](0014-isolated-strategy-workers.md) 独立策略 Worker
- 尚未决定：具体数据供应商、首批数据接口、Data Manager / Worker 的接口格式、平台网络沙箱实现、质量与冲突阈值。已确认合格备用源自动切换行为见 [ADR-016](0016-verified-data-source-failover.md)。

## 问题

生产策略可能需要行情、宏观、财务、新闻等信息。若允许 AI 生成的生产 Worker 任意访问互联网，将增加凭据泄露、非授权请求、不可复现输入、调用费用和网络故障的不确定性。若所有数据源都由 Owner 手工注册，又会把 Agent 本应自主完成的研究工作变成重复的人力审批。

## 已接受决策

1. **研究发现自由、生产访问集中。** Agent 在与交易核心隔离的研究环境内，可按权限和费用约束探索公共/获授权的数据源，比较质量和成本、提出接入候选。**生产策略 Worker 默认无任意外网出站权限**；必须通过可信 Data Manager 接口获取经治理的数据。
2. **Data Manager 是可信访问边界，不是给 Agent 的提权接口。** 它负责已获批准来源的适配器/连接配置、密钥保管、请求费用和频率约束、许可范围、缓存、时间/来源标记、质量检查与失败反馈。研究 Agent 不能直接安装执行任意来源代码到可信核心，也不能改写访问白名单、访问密钥或生产执行权限。
3. **自动化为默认体验。** 内置且可合法获取的免费公开来源可以在既定使用政策内自动选择和使用，不逐站弹窗。Agent 可自动发现新来源并进行隔离研究和候选登记；新来源接入生产前应通过最小必要的功能、安全、许可/质量核验。成熟的内置适配器可自动启用；不意味着“发现 URL 即获得生产核心执行权”。
4. **明确授权只在真正需要时发生。** 新服务需要 Owner 提供 API Key、付费/订阅承诺、或向新的接收方发送个人账户敏感数据时，需要首次明确授权；此后按 ADR-013 的“接收方/用途/数据范围”持久复用，不因后续正常取数反复询问。Agent 不得擅自付费、自动充值，按 ADR-012 限制研究费用。
5. **凭据与网络隔离。** 供应商凭据只在可信连接组件安全存放和使用，Worker 不能读取凭据、请求任意目的地、借 Data Manager 向任意 URL 代理请求，也不能接触券商和生产账本写权限。可信数据接口必须使用预定义的数据类别和访问策略，避免被当作开放代理/SSRF 通道。
6. **数据可追溯与失败透明。** 数据须带来源、时间、版本和质量信息，遵循 ADR-005 的 `event_time` / `available_at`。依据 [ADR-016](0016-verified-data-source-failover.md)，主源出错时已验证的合格备用源自动接管；两源不可信或存在无法解释的重大冲突时，只阻止受影响策略新增风险，不得编造价格或自动清仓。
7. **隔离并非断网即完成。** 本地/远端 Worker 的网络出口和文件/密钥/IPC 权限均需真实 OS/基础设施限制及测试。若某平台做不到安全隔离，不应声称可在同台带券商凭据的主机上安全执行不可信代码。
8. **轻量实施。** Data Manager 是逻辑边界，不要求另建一个微服务。M0 不做任意来源插件市场或通用网页爬虫，不接真实数据/券商；后续从少量有价值的可信适配器、简单标准化数据接口做起。保持自动发现与生产数据准入分离。

## 后续 P0/P1 验收方向

- 生产 Worker 直接访问非许可外部域名、任意 URL 代理或读取供应商/券商密钥的尝试失败。
- 可合法使用的内置公开行情源无需每次 Owner 手动填写/审批；需要付费或敏感数据发送的新权限不能由 Agent 偷偷开启。
- 适配器的数据时间、版本、来源和异常状态被准确传递，不能把过期/未知数据假装成新鲜且可执行的信号。
- Data Manager /外部接口故障不能绕过本地风险和订单通道；无真实数据时不凭空构造成功回测。
- GitHub 或本地日志不得存储明文 API 密钥和可识别的券商登录信息。

本 ADR 仅确认设计方向；当前 M0 依然是未接入数据源、Worker 与真实券商的骨架。
