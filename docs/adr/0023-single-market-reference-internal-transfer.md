# ADR-023：内部虚拟份额转移使用单一可信市场参考价

- 状态：已接受（Accepted）
- 日期：2026-10-27
- Owner 选择：方案 A。策略组之间进行可信内部虚拟权益转移时，转出和转入两端按**同一个市场参考价格**记账，不虚拟制造买卖价差。
- 关联：[ADR-021](0021-group-isolation-shared-instrument-attribution.md) 策略组归属、[ADR-022](0022-trusted-cross-group-intent-netting.md) 净额执行、[ADR-016](0016-verified-data-source-failover.md) 数据源质量、[ADR-019](0019-account-and-strategy-risk-layers.md) 双层风险。
- 尚未决定：参考价格的具体市场字段（例如适当成交价或买卖盘中间价）、数据刷新/时效阈值、批量匹配时间窗口。外部订单部分成交同级按比例归属的方向已由 [ADR-024](0024-prorata-partial-fill-attribution.md) 确定。

## 问题

两个策略组在同一时点对同一证券产生相反意图并能够合法地转移其内部归属时，系统需要为账面份额转移确定一致的成本与盈亏归属。若分别采用买入侧和卖出侧报价且无实际券商成交，可能在内部虚拟账簿中凭空产生价差、费用或账户利润。

## 决策

1. **同一时间、同一可信参考价：** Portfolio Allocator 对一次获准的内部虚拟份额转移，选用一条带证券身份、行情时刻、数据可得时刻（`available_at`）、来源/版本与参考价字段的可信报价。转出组与转入组使用**完全相同的单价、数量与事件 ID**；不得让研究 Agent 或任一组选择对自己更有利的估价。
2. **仅改变内部归属，不产生券商成交：** 该记录是 `INTERNAL_ALLOCATION_TRANSFER`（命名为示例），不等于交易所撮合、券商成交、结算交割、账户现金变动或真实市场买卖手续费。真实账户持股数和现金总额在事件前后不变，组级虚拟持仓总量需与已核实的账户持仓保持一致。
3. **区分组级表现与真实账户损益：** 按相同参考价格可将转出组此前的虚拟未实现盈亏转入其内部已归属结果，并将转入组以此价格设为新的虚拟成本基础；但这是**组级绩效归属口径的调整，不是新增真实已实现交易损益**。组别的盈亏、资金或成本基数变动必须可加总/对账；不能在会计上重复确认整个账户的利润、转移份额或税费。
4. **无真实摩擦就不伪造真实摩擦：** 不向真实券商下单的内部归属转移，不计作真实交易佣金、印花税、滑点或虚拟买卖价差。研究报告若希望评估独立策略在假设实际交易时的隐含执行成本，可以另行标示为**模拟机会成本**，绝不记入实际账户已发生费用。
5. **报价可靠性是硬前置条件：** 参考价只能来自可信 Data Manager 和经过验证的新鲜、可比、符合许可的数据。证券身份、币种、复权/原始价、交易时段、时间精度或质量不可信时，拒绝或延迟内部份额调拨，不能靠缓存旧价、猜价或选边获利；符合 ADR-016 的备用源可经验证自动接管。
6. **先核实真实持仓和交易限制：** 仅在可确认转出组有足量内部归属、实际账户有可用对应持仓，且相关流转符合已批准的交易/结算模型与限制时，才执行原子化归属事件。不得借内部调拨虚构可卖股份或绕过 T+1、停牌、Owner 禁令、未成交订单和策略/账户风控。内部转移不代表能够当日从券商卖出这部分实际证券。
7. **可重放、可审计：** 保存匹配的两端 `group_id`、源意图与目标意图、`artifact_hash` / `deployment_id`、同一报价快照 ID、价格/数量、原始成本基数、内部资金/风险额度占用变化和审核结果。保证一笔内部虚拟事件不会因重试或重启被重复应用；不改变组内私有研究输入、其他组策略信号或历史实验结果。
8. **工程边界：** M0 仍保持单组纸面资金与风险闭环。不在此阶段实现跨组内部转移、通用报价选择引擎或复杂财务归因；后续在真实多组需求出现时，以最小可信账本及验收示例实现。

## 未来验收示例

- 组 A 买 100、组 B 卖 100 且内部归属转移合法，可信参考价为每股 100：A 增加 100 股虚拟份额、B 减少 100 股，使用同一价格快照；真实账户持仓和现金保持不变。
- 组 B 之前的虚拟成本为 90 时，其内部表现记录可以区分归属收益与**实际券商已实现收益**；A 以 100 为新虚拟成本，不能凭空增加整个账户 1,000 元的财富或税费。
- 报价缺失、重大冲突或过期时不能强行内部匹配；份额不足或 T+1 风控不满足时不能借内部转移清洗库存。
- 内部转移多次处理或程序重启，不重复生成份额或转移盈亏；组级份额总和仍与真实账户持仓一致。

> 此 ADR 为未来内部归属计价规则，当前 Stratide M0 无跨组净额器、真实行情订阅或券商接入。
