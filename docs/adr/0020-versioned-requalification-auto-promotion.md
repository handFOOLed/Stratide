# ADR-020：新策略版本的重新评估与自主准入

- 状态：已接受
- 日期：2026-10-27
- Owner 选择：B，新版本经过独立完整验证后可以自主准入，不要求每次人工批准。

## 定义

策略家族 `family_id` 表示研究血缘；`artifact_hash` 唯一标识冻结的代码、参数与模型版本；`deployment_id` 关联实际运行与订单归属。参数变化会产生新工件，但新哈希并不自动表示不同的经济风险。

## 决策

1. 已停止的旧版本保持历史风险记录与原有状态，不因生成新版本而自动重置。
2. 新版本必须接受完整的独立评估、前向观察、可信准入与账户及策略两级风险核验。
3. 新版本符合既有 Owner 授权范围、未命中用户明确的有效禁令后，可以自动准入，无须逐个人工确认。
4. 版本之间保留研究血缘及风险关联，不能把重复的真实账户资金和仓位算成额外可用资本。
5. Owner 的主动禁令按其实际设定的范围执行；精确版本还是整组生效的选项待后续决策。
6. 整个账户仍受账户级风控约束。具体关联风险评估方法在后续实现阶段设计。
7. 当前 M0 不包含自动策略部署功能。

## 验收

旧版本历史保持可审计；新版本只能凭完整独立证据获得准入资格；组合资金没有重复计算；用户的禁令仍有效。
