# ADR-005：探索数据与可用于策略晋升的证据分级

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- 决策范围：研究数据的使用、回测可信性、策略晋升所需数据证据
- 非本 ADR 决策：具体数据供应商、正式验证阈值、固定纸面交易周期、样本外多重检验方法

## 背景

免费或低价历史行情/财务数据未必完整保留当时的发布时间、可得时间、复权与修订版本。禁止这些数据进入任何实验会妨碍开放研究；但允许使用事后修订数据做所谓“真实历史回测”，则可能产生未来信息泄漏并误导实盘决策。

Owner 选择方案 **B：数据可信度分级**。研究自由，真实资本晋升需要独立可信的证据。

## 决策

1. **EXPLORATORY（探索性）**：时间可得性未验证、来源不完整或疑似存在事后修订的数据可以用于形成假设、调参和初步实验，但结果必须标为“探索性”；不得单凭此类表现晋升到实盘，不能伪装成可交易的历史收益。
2. **POINT_IN_TIME_VERIFIED（逐时点可得性已验证）**：独立评估器可使用有来源、正确事件时间与真实可获取时间、版本/修订处理记录的数据执行正式历史样本外评估。任一策略决策只能读取当时已可用的信息（`available_at <= decision_time`）；数据源名称或“历史数据”标签本身不能替代验证。
3. **FORWARD_OBSERVED（前向观察）**：缺失可信历史可得性的数据研究成果，仍可进入**隔离的前向影子观察/模拟**，但不得把事后回填的历史表现计为独立证据；需要从真实观测时刻起记录信号、输入版本、决策时间、订单意图与模拟执行结果。
4. **阶段隔离**：自由探索 → 独立资格评估 → 前向模拟/影子交易 → 满足另行定义的实盘晋升门槛。进入前向研究不等于正式通过晋升，更不意味着有真实下单权限。
5. **避免伪证据**：需要留意财报公布及修订、生存者偏差、退市样本缺失、复权方案、停牌/涨跌停、交易成本与成交可实现性；不要求所有数据源都有一样复杂的元数据，而要按策略所用字段与真实财务风险决定核验深度。
6. **独立验证权限**：Research Agent 可以使用探索性数据并自主提出假设，但不能自行把数据或实验结果“升级”为可信证据。独立 Evaluator 对证据标签与资格判断负责。
7. **经济与工程约束**：不为纯探索数据建立穷尽格式测试或昂贵数据采购体系；只在候选策略具备足够价值、可能接近真实资金晋升时投入相应验证成本。

## 最小关键验收（未来实现）

- 回测查询若包含晚于决策时刻才公开的财报，应被正式评估器拒绝，而不影响普通探索实验。
- 探索性回测再漂亮，也不能直接获得真实资金订单权限。
- 前向模拟数据按发生时记录，不允许用事后获知的信息改写原始决策证据。
- 数据可靠性不足且无法前向累积证据时，候选保持研究状态（No-Edge/No-Promotion），不能自动放行。

本 ADR 仅确定证据边界；M0 不需要接入真实数据源或实现完整数据分级平台。
