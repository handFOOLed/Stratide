# ADR-037：先交付可观察的模拟交易；Sol 开发、Terra 验收合并、ChatGPT 审查

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- Owner 决策：先完成可运行、可持续观察的**模拟交易（Paper Trading）**，暂不继续无限扩展架构问答；GPT-6.1 Sol 专职编码，GPT-6.1 Terra 专职独立测试、验收及满足门槛后的合并，ChatGPT（小猫）负责架构与代码审查，Owner 观察效果并确定下一阶段。
- 实施计划：[PAPER_TRADING_ROADMAP](../PAPER_TRADING_ROADMAP.md)；本 ADR 不表示模拟交易已经完成。
- 继承约束：ADR-002/003/005/006/007/008/017/018/019 等已接受风险与数据语义；真实交易功能需要另行批准。

## 为什么做出这项决定

当前仓库还是 M0 Rust Workspace/CLI/Daemon 的 scaffold，无行情接入、订单/风险/持仓真实闭环或研究 Agent。进一步细化几十项未来券商/多策略边界，不能取代对最小交易系统进行代码验收与实际观察。

用户需要的不是“cargo check 通过”或图表演示，而是可追溯的订单、净值、风险拒绝和持仓变化，并能区分历史回放与严格的未来时序模拟观察。

## 决策

1. **以可运行的 paper-only 交易闭环优先。** 实现一个单策略/单账户模拟核心：明确的 Owner 配置起始本金、可复现交易提案、独立 Risk Kernel、保守模拟撮合、现金/整数股/成本/持仓账本、订单事件持久化与重启恢复。不得连通可提交真实委托的券商功能，默认不存在真实交易能力。
2. **分阶段交付，不混淆结果证据。** 第一里程碑 M0-Paper Core：小型固定真实或标注为合成的历史数据进行确定性复盘、关键风控单测和重启校验。第二里程碑 M1-Observable Paper：在 M0 正确基础上使用实际可合法获取、经验证的历史市场数据和时间推进的**前向模拟记录**，留下运行日志与日报。历史回放、合成数据测试、前向纸面交易必须分别标注；不得冒充真实券商成交、真实盈利、交易所逐笔撮合或未暴露的样本外结果。
3. **观察比 UI 复杂度优先。** 起步提供 CLI `status/run/report` 等等价操作及 CSV/JSON 可读报告：模拟 NAV、现金、可卖/冻结持仓、委托与成交、已实现/未实现损益、手续费、风险拒绝原因、每日收益、最大回撤、策略与简单基准比较。CSV 可绘制曲线；第一阶段不强制 Web Dashboard/K 线终端。
4. **保守行情/撮合语义。** 实际数据必须保留证券、来源、时区、交易日、复权/原价语义和当时可得信息。不得用当天收盘结果在当天收盘已成交来构造无延迟盈利。先支持窄范围 A 股日线与明确成本/交易规则（按品种适用的 T+1、价格限制、整手、停牌）；数据不支持的交易规则按保守停单而不是暗中允许。缺少真实数据时先完成自洽测试，不伪造“实际市场效果”。
5. **单一合并治理流程。** Sol 编码、自测并建立可审查 PR，**不自行合并**。Terra 以独立视角从干净工作树复现本地/CI 可用测试，执行验收与故障注入，发布测试证据，必要时将问题退回 Sol。ChatGPT 审查 PR diff、架构/风险不变量和 Terra 的测试证据并提出必须修复项。Terra 只在测试通过且审查阻断已解决后**执行合并**；不以“测试自己写的补丁”替代独立性。
6. **Owner 是范围与风险授权者。** Owner 可决定改范围、终止方案或暂缓合并、实盘启用。任何模型无权自行扩展为真钱交易、修改资金上限或因为回测利润不错而批准真实执行。ChatGPT 的审查需明确由 Owner 发起 PR 评审/提供 PR 链接，不能假设自动持续监听 PR。
7. **证据化验收，拒绝自评合格。** Sol 的自测不是 Terra 的独立验收，Terra 的通过不是 ChatGPT 的代码审查。报告必须列明 commit/PR、输入数据来源/区间/快照哈希、命令与运行环境、通过/失败项目、净值及风险不变量、已知缺陷。重要资金一致性/重放/重复成交/超额买入/亏损熔断失败是阻断项。无需昂贵 CI 或复杂云服务；不能执行的平台注明未验证。
8. **阶段边界。** M0 最小模拟内核通过后，才接入 M1 真实市场数据/前向模拟观察；不在同一 PR 混入 Agent 自主研究、多组真实归属、AI 策略生成、自适应头寸、线上券商或复杂 GUI。后续实际效果评估可与低成本基准比较，但模拟回报不构成可赚真实资金的证据。

## 验收案例

- 资金不足、未满足 A 股可卖/交易规则、亏损熔断状态、未知重复事件等不会让现金或股数出现不可能值；相同输入复盘净值/成交一致。
- 程序停止/重启后恢复原样的模拟账本，不重复成交、漏记资金或解除原风险锁。
- 能在独立报表中解释每次模拟成交发生的时点、行情来源、价格/费用/持仓变化和拒单原因；无数据的日期不得生成“真实市场交易”。
- 历史回放与前向观测都有来源、起止、生成时点标签，不会把回看历史包装成真实未见过的验证记录。
- Sol 的 PR 经 Terra 独立验收、ChatGPT 结构化审查后才由 Terra 合并；未解决的高优先级问题阻止合并。

> 此决定确立开发目标和职责，而非确认任何特定 Codex 型号的实际调用/连接权限，也不授权本助手在后台持续监控 PR。
