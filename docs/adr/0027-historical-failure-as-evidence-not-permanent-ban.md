# ADR-027：历史失败作为研究证据，而非自动永久禁研

- 状态：**已接受（Accepted）**
- 日期：2026-10-27
- Owner 选择：**方案 B：历史上失败的策略或相似策略可以再次被研究，但必须参考已知失败证据；失败记录本身不构成永久研究禁令**。
- 关联：[ADR-026](0026-budgeted-shadow-observation-and-local-strategy-registry.md) 本地注册表与限额检索、[ADR-006](0006-independent-validation-isolation.md) 独立验证与防过拟合、[ADR-012](0012-adaptive-research-daily-hard-budget.md) 研究费用上限、[ADR-020](0020-versioned-requalification-auto-promotion.md) 新冻结版本独立准入、[ADR-021](0021-group-isolation-shared-instrument-attribution.md) 策略组资料隔离、[ADR-025](0025-adaptive-risk-budget-decay-quality-gates.md) 策略失效监测。
- 待定：研究相似度具体算法、新研究假设记录格式、重新研究优先级/频率及多次试验证据折扣、跨组可共享的匿名失败知识范围（默认不共享私有内容）；具体费率、统计检验阈值不得被假定已配置。

## 背景

研究 Agent 可能在若干月后重新提出与过去失败策略高度相似的假设。若本地 Registry 一旦标记失败就永远拒绝同类研究，可能错过新数据、新机制、改进的执行方法或市场制度变化；若无视过去研究，又会反复花费 Token/计算预算试错并发生数据挖掘偏差。

## 决策

1. **失败不是永久禁研。** 策略研究出现负收益、样本外失效、执行成本过高或异常市场下表现差等历史记录，默认只作为需要解释的**研究证据**，不单凭失败标签禁止 Agent 后续探索类似策略。市场环境和可验证假设可能变化，但不能据此假定过去失败已不相关。
2. **先本地查重和检索证据。** 通过 ADR-026 的可信本地 Registry 对冻结工件哈希、研究血缘、特征标签、数据指纹和廉价数值行为相似性筛选历史候选。哈希相同提示工件重复，不是唯一相似性标准；哈希不同不代表市场风险不相关。检索应返回少量授权摘要与来源引用，避免向 LLM 送入策略全集。
3. **再次研究应提出可检验的新增理由。** Agent 在启动有实际成本的重复/相似研究前，标明关联的既有失败证据、可能改变的条件（如新样本、市场机制、特征构造、费用/执行假设或结构性修正）、预期差异与证伪方法。无需固定人工审批，也不强制 LLM 对每次精确重复都做长篇论证；对于完全相同数据/工件/评测设置，可复用可信已缓存结果，避免无意义重复付费调用。
4. **独立实验与信息泄漏边界不变。** 有新理由可以启动探索性研究，**不**直接恢复原策略实盘资格。冻结的新版本仍必须重新进行独立 Evaluator 测试与真实前向观察，遵循 ADR-006/020。不可通过反复阅读旧留出集答案、调参后再把同一数据标为“新样本外”，或把回看历史市场后的再测试成绩冒充前向证据。
5. **失败证据不允许消失或被粉饰。** Registry 持续关联相关失败记录、失败时市场与数据版本、风控/执行背景、测试尝试和可能的偏差。升级版本不能重写旧版失效历史；Agent 也不能选择性过滤坏样本、隐藏多重尝试或将失败仅描述为“名称相似但无关”来规避重新认证。
6. **研究权限与交易权限严格分离。** “允许重新研究”不代表可解除 Owner 主动禁令、账户级风险熔断或旧版本财务锁；禁令范围仍按其有效权限执行，未知禁令范围不得擅自当作解除。Agent 可在受限研究环境研究已失效思路，但任何新的实盘资格、风险预算及实际下单都走独立验证、Owner 既有授权、Risk Kernel 和 Promotion Gate。
7. **跨组资料隔离。** 相似性检索按 `group_id` 与授权范围过滤；默认不能向 A 组 Agent 提供 B 组私有策略描述、信号、研究日志、模型参数或失败案例全文。未来如果 Owner 明确允许可使用经过可信聚合/脱敏且经检查不泄露私有信息的通用失败模式摘要；具体共享范围尚未批准。共享公共市场数据和可信组合风险总量不视为组间私有研究交换。
8. **预算内自主规划。** 历史失败提示可以减少重复云端 Token、回测和算力开销，但本地检索也有资源成本。新增研究需经过 ADR-012 的每日研究费用闸门与 ADR-026 的检索、存储、观察池资源上限；预算不足就推迟，不依靠“上次失败，这次肯定有效”来申请越权扩容。研究优先级应基于可被检验的新证据，而非 Agent 自述的创新程度。
9. **实现要小且可验证。** M0 仍是单组 paper-only 最小闭环，不实现全量策略查重、语义向量数据库、LLM 自主实验调度或动态复活机制。后续 Registry 可增加轻量失败原因/引用字段和重复候选提示，不引入永久策略黑名单系统。

## 未来验收

- 曾失败的策略有明确新数据/机制假设时可进入受限探索；仅失败标签不会自动阻止研究。
- 相同工件/相同数据/相同试验条件能命中可信已有结果，减少重复计算；参数不同但高度相似的候选能获得历史血缘与失败提醒，而不会被自动认定完全独立。
- Agent 不能因再次研究或换哈希清空历史亏损、旧版冻结、账户熔断或 Owner 有效禁令。
- 新候选的独立评估/前向证据不能因为读取旧失败记录就假冒未见过的数据。
- 组别隔离依然有效，检索上下文和付费研究受资源预算限制，旧失败证据持续可审计。

> 本 ADR 是策略研究知识复用原则。Stratide 当前为 M0 工程骨架，没有可用的自动策略研究、注册表检索或实盘重新晋升模块。
