# ADR-022：跨策略组交易意图在可信组合层统一净额处理

- 状态：已接受（Accepted）
- 日期：2026-10-27
- Owner 选择：方案 A。策略组独立输出交易意图，可信 Portfolio Allocator 在执行前归并同一证券的相反意图，避免不必要的真实委托。
- 关联：[ADR-021](0021-group-isolation-shared-instrument-attribution.md) 组内数据隔离与虚拟持仓归属、[ADR-019](0019-account-and-strategy-risk-layers.md) 双层风控、[ADR-008](0008-dynamic-portfolio-capital-cap.md) 唯一实际资金池、[ADR-002](0002-in-process-risk-gateway.md) 强制订单通道
- 待决定：可信参考价的具体行情字段和时效阈值、时间聚合窗口、部分成交分摊和冲突优先级。内部转移使用同一市场参考价、不产生真实手续费的原则已由 [ADR-023](0023-single-market-reference-internal-transfer.md) 确认。

## 设计意图

两个独立策略组可以就同一标的给出不同甚至相反的意图；这不意味着必须向券商发出一买一卖两笔可以抵消的实际订单。Owner 要求各组的研究与信号互不干扰，净额执行只发生在受信任的组合层。

## 决策

1. **策略决策独立。** 各组继续独立产生带有 `group_id`、`artifact_hash`、`deployment_id`、证券标识、方向、数量/目标仓位、时间与有效期的交易意图。任何组的私有信号或内部模型状态不得成为别组的未授权输入；组合层只读取执行与账户风险核验必需的标准化提案。
2. **统一聚合后产生外部净订单。** Portfolio Allocator 在受信任边界内，按同一证券、可兼容的交易时点与约束合并买卖需求，计算账户层面必须实际买卖的净额，再交给独立 Risk Kernel 审批，最后由 Execution 产生真实券商订单。净额为零时可以不向券商提交新单；不能将未执行的相反意图自动记为已在交易所成交。
3. **双层风险不能被净额掩盖。** 进入执行前要验证各组持仓/资金可用性、所属策略状态和预算限制，并检查净额交易后的账户敞口、未完成委托与现金占用。净额为零不意味着风险一定为零：策略归属、集中度、交易限制及账户持仓真实性仍要满足要求。
4. **内部虚拟归属可以调整，但须单独记账。** 若 A 想买 100 股、B 想卖 100 股，且 B 确实有允许调拨的、已确认且可交易的份额，组合层可按 [ADR-023](0023-single-market-reference-internal-transfer.md) 的双方统一可信市场参考价格记一项可追踪的**内部虚拟权益转移**，不向券商发单；组合真实持仓仍不变。该事件不是券商成交，不能伪装成真实成交回报或新增现金，不得制造未实现的真实收益。虚拟收益归属与账户实际收益必须分别报告。
5. **不能通过内部账簿绕过交易约束。** 不得以内部虚拟份额转移或组间净额交易，绕过实际证券的交收与可卖数量、A 股 T+1、最小委托单位、停牌/涨跌停、真实现金可用性以及策略/账户熔断。若不具备合法且清楚的内部转移条件，拒绝/延迟不合格部分，而非虚构可卖库存或同日成交。
6. **剩余单边净额以真实成交为准。** 若 A 买 200 股、B 卖 100 股，内部归属只在有效可调拨份额内抵消；若确有净买入 100 股，新增真实持仓和费用必须以券商确认的订单/成交及权威现金账本为准。部分成交时按可信、可重放、事前确定的归属规则分配，不让 Agent 事后挑选获利的分摊方式。
7. **执行与归因分离、可复原。** 保留各组原始意图、内部净额撮合/调拨记录、送券商实际订单、最终成交以及各组成本与净值更新的对应关系。失败、取消、重启或券商结果不明时，不得先将归属账本推进到无法与真实状态对账的假设状态。依 ADR-003/017 持久化并核对。
8. **不过度设计 M0。** 仍先完成单组 paper-only 的受信任提案→风控→账本闭环。后续真需要多组同股交易时再做轻量净额器及一致性测试；不搭建交易所式撮合平台，也不要求每次分组执行都取得用户许可。

## 财务验收方向

- A 买 100、B 卖 100 且 B 有有效可调拨份额时，账户真实净订单可为 0；两组虚拟持仓变化可追溯、总持股和现金不变。
- B 无可卖/可转移持仓时，不能通过 A 的购买意图虚构 B 的卖出与实际兑现收益。
- 各组产生信号互不读取对方内部研究数据，但账户和策略双层风控均在净额执行前强制生效。
- 只有券商确认的实际成交才能更新实际现金与证券；部分成交、订单状态未知、重启等情况下账本可对账，不双计交易费用/资金。
- 内部转移双方使用同一可信参考价且不得制造真实手续费或账户利润（ADR-023）；具体行情字段、匹配窗口与部分成交分摊规则需在正式实现前确定并保证可复现。

> 本 ADR 为未来多组组合管理的设计决定。当前 M0 仍无真实净额执行器、券商接口或多组虚拟账本。
