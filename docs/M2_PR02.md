## Windows 一键启动与第一次研究

需要现有 PowerShell 7、Rust/MSVC 和 Node；不安装服务或计划任务。后台研究只在本机进程运行期间推进。

```powershell
# 确定性 fake：独立本机 Agent 数据 + 仓库合成 Paper 报告。
pwsh -NoProfile -File scripts/start-dashboard.ps1 `
  -ReportDir docs/evidence/m0-pr03/sample-report `
  -AgentDir state/agent-fake -FakeAgent
```

脚本完成 npm ci、前端 build、Rust build、fake 初始化、Windows 目录 ACL 与健康检查，打开 localhost。`-NoBrowser` 可用于无可见浏览器的启动验证，`-NoBuild` 复用已构建产物。`-FakeAgent` **只在配置不存在时初始化**，不会覆盖已有 Owner 配置；要隔离测试请选新的 `state/…` 目录。未传 ReportDir 时没有默认账户或本金。

进入「Agent 管理」，从本机指定目录的 `owner-token` 复制令牌，解锁本次页面。令牌只保留在页面内存，刷新后需重新解锁。它是本机控制凭据，不要上传或共享。选择默认 fake，点击任务列表右上角「自定义任务」，填写名称、目标、范围和日期。完成后点击任务名打开右侧抽屉。打开详情与刷新只查询本机 SQLite。

本地 fake 配置包含 success、safe_transient、timeout、slow、malicious 文本场景，供可复现故障验证。模型切换只影响**新建**任务；已排队任务也固定原模型与配置哈希。fake 使用 `TST` 测试币种，没有付费网络请求。

## Owner 配置真实云 Provider

真实路径是可替换的 `chat_completions_v1`：非流式 HTTPS POST，`model/messages/max_completion_tokens/stream=false/n=1`，响应读取 `choices[0].message.content` 和 `usage.prompt_tokens/completion_tokens`。协议参考 [Chat API](https://developers.openai.com/api/reference/resources/chat)，这不表示已经选择该供应商。其他服务必须实际兼容此请求/用量契约；V1 不探测或自动购买供应商权限。

1. 在本机独立目录保存可信设置。模板 `research/agent-settings.example.json` 中 budget=null、models=[]，可安全启动但不能付费。配置文件和运行数据保存在 git-ignored `state/…`；不要放入被跟踪的 `research/` 源码目录。
2. Owner 自行选择服务/模型与**确切 HTTPS API URL**，确认所用纯文本 API 的最大输出上限、输入 token 上界、价格来源与价格版本。V1 没有浏览器 URL/Key/预算编辑入口。`models` 可保存至多 16 个配置；Web 可以选择已保存的默认/备用 ID。
3. 填写 `budget`：三位大写计价币种、IANA 时区、`daily_limit_micro` 和 `monthly_limit_micro` 正整数。**1 货币单位 = 1,000,000 micro**，不能用 0 表示无限。没有默认真钱金额。该费用预算与 Paper 本金分离。已建立账本的币种/时区不可直接改写，避免重置期间；限额可由 Owner 修改本机配置，发送前重新读取。不要通过删除/另建费用账本逃避未结清预留。
4. 按下列字段保存模型，替换所有尖括号占位。`price` 和 `grant` 未配置时继续 fail closed。

```json
{
  "id": "owner-primary",
  "label": "Owner 主模型",
  "kind": "chat_completions_v1",
  "model": "<Owner选定的实际模型名称>",
  "endpoint": "https://<Owner选定的公网主机>/v1/chat/completions",
  "api_key_env": "STRATIDE_RESEARCH_KEY_PRIMARY",
  "max_input_tokens": 32768,
  "max_output_tokens": 1024,
  "timeout_seconds": 30,
  "price": null,
  "grant": null,
  "fake_scenario": null
}
```

`price` 的字段为 `version/source/currency/input_micro_per_million/output_micro_per_million/bounded_text_billing_verified`。输入/输出费率单位均为 **每百万 token 的 micro 货币数**；例如报价单位转换由 Owner 根据真实费率填写，不内置供应商品牌或金额。`bounded_text_billing_verified=true` 表示 Owner 已核实该模型没有工具费、最低收费或其他未纳入上界的计费类别。无法确认时保持 false，不能无人值守付费。上例 token 数是资源边界，Owner 必须确认实际模型支持；它不授予付费额度。

`grant` 的字段为：

- `receiver`：必须与该模型 endpoint **完整一致**；`purpose` 固定为 `paper_research_v1`。
- `scopes`：Owner 明确选择 `owner_task`、`paper_summary_v1`，以及使用独立历史评价摘要时的 `historical_summary_v1`。数据源摘要包含来源模式/源日/版本、报告日期数、模拟成交/拒绝数、总收益/回撤摘要和缺估值计数；历史评价只含证据/工程标签和区段数。
- `authorized_at`：Owner 本次授权时间；`revoked=false`。撤销设为 true，发送前重新校验；不能删除已发给服务商的记录。输入始终不包含身份标识、账户现金明细、逐笔交易、原始行情、组私有信号或 protected holdout 答案。Owner 应在授予该接收方时核对实际数据可外发范围与服务商保留政策。

5. 将 Key 设置到启动进程的专用环境变量（示例名 `STRATIDE_RESEARCH_KEY_PRIMARY`），由安全的本机环境/秘密管理工具注入。Key 不写 settings.json、网页、URL、localStorage 或日志；Agent 不能选择其他环境变量名。Owner 令牌与云 Key 各司其职，不向云端发送 Owner 令牌。
6. 设置 `default_model="owner-primary"`，按需保存 `backup_model`。首次配置建议停止测试服务后使用真实配置重启：

```powershell
pwsh -NoProfile -File scripts/start-dashboard.ps1 `
  -AgentDir state/agent-real -AgentConfig '<本机可信settings.json>' `
  -ReportDir '<Owner明确选定的既有六报告目录>'
```

7. 页面显示预算、价格版本和授权状态后，由 Owner 提交一个小范围任务作为**真实连通性验证**；这仍经过相同日/月/单任务预留。详情保存真实成功/失败、token 与费用不确定性。没有有效授权、可靠价格、预算或 Key，不发请求。当前交付没有 Owner 真实配置，外部连通性为 **REAL_PROVIDER_NOT_VERIFIED**。

仅允许公网域名的 HTTPS 443 `/…/chat/completions`，不允许 userinfo、查询串、重定向、字面 IP 或本地域名。发送前解析 DNS，拒绝私网/环回/链路本地等地址并固定本次解析结果；关闭系统代理和传输自动重试。实现使用 [reqwest 的客户端控制](https://docs.rs/reqwest/0.12.28/reqwest/blocking/struct.ClientBuilder.html)。错误不返回包含 Key、响应原文或本机路径的调试信息。

备用配置可以保存和展示；V1 **明确关闭自动切换**。主配置不可用时任务失败/不确定，Owner 可切换默认配置以创建后续任务。不会把未知付费请求复制给备用模型。

## 任务与费用语义

任务状态为 queued/running/completed/failed/cancel_requested/cancelled/outcome_uncertain。单 worker，不声称并行。手动任务在资源允许时尽快执行；每页 20 条，默认上限 1000 任务、64 MiB 研究数据库。达到限额停止新研究，不自动删除审计/财务证据。V1 不提供归档/清理平台。

优雅暂停持久化并阻止开始新任务，已运行任务允许完成；重启不解除暂停。排队任务可立即取消；运行中记录 cancel_requested，在不可中断的已提交请求完成后保存已有结果和费用，再结束。未知结果保持 outcome_uncertain，取消不撤销外部费用。

只有确定未产生外部费用的安全瞬时失败最多自动重试一次；所有调用尝试分别记录。V1 真实网络错误（含 HTTP 错误）均按费用可能未知保守处理，不自动重发；fake 可明确证明安全未发送场景。详情仅为读取，不能再次发起总结。手动「安全重试」也仅对尚未付费且未用尽两次调用尝试的 failed 任务开放；模型/授权配置变更后原排队版本拒绝发送，需 Owner 新建任务。

每次可能付费的请求前，SQLite `BEGIN IMMEDIATE` 原子检查当前日/月已核对额 + **所有周期未结清最大预留** + 本次保守上界。使用整数 micro 和向上取整，按 Owner 时区固定预留归属日/月。日/月/单任务任何一个不足均不进入 send。模型切换不创建新预算。

云端返回 token 和估算费后仍保留完整最大预留，直到 Owner 核对外部账单；不把用量当最终实收。unknown、取消、崩溃、跨月均不释放不确定费用。fake 的用量与费用是确定性合成值，可以立即结算。供应商计费与本地上界有偏差的可能，不能承诺供应商最终账单必然不超限。确认超出上界会持久阻止新调用，不能靠换日期/模型清除。

服务重启时，reserved 且从未写入 dispatch 标记的尝试可安全释放并恢复排队；dispatched 之后的运行任务转为 outcome_uncertain，禁止重发。单独文件锁禁止两个研究 writer 同时接管同一目录。费用账本与 Paper v3 Ledger 完全分离。

外部账单核对只在**停止研究服务后**由 Owner 在本机执行，不向 Web/Agent 提供权限：

```powershell
./target/debug/stratided.exe --agent-settle '<Agent目录>' '<call-id>' '<实际micro整数>' '<账单凭据引用>'
```

这不会把任务执行结果变成已知或自动重试，也不把费用记入 Paper NAV。超额/违反计费上界后没有 Web 清锁按钮，需 Owner 查明来源和预算政策；不要直接改 SQLite 或删除账本释放费用。

## EOD 自动研究与数据隔离

EOD 默认 OFF，Owner 可在页面显式启用。后台至多每 60 秒从**启动时明确选定的报告/评价路径**读取并重新校验六报告摘要。只接受 `historical_replay` 中已验证状态、有有效末日估值的当前交易源日，并在 Asia/Shanghai 16:00 后触发；从报告源日识别会话，不把周一至周五猜成交易日。synthetic、旧报告、损坏、未验证状态、无新有效数据都不自动付费。

同一源日 + eod-v1 的 trigger_key 唯一；数据修订不会造成同日重复调用。暂停时只记实际看见的 skipped_paused，恢复只考虑最新有效源日，不逐日补费或伪造停机期间观察。旧 queued EOD 会标 skipped_superseded 并取消，手动课题不被合并。服务必须保持运行才能观察发布，不安装系统级唤醒任务。

账户 API 始终保留启动时固定快照，Agent 更新研究输入不会刷新账户 NAV。研究只接触可信摘要和 Owner 课题；输出只有假设/依据/反证/下一步，按文本转义展示，不能执行模型生成代码、任意 URL 抓取、读取其他文件、写财务/风控、调用 paper-apply 或自授策略资格。
