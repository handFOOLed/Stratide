## 事件时钟与唯一财务路径

策略仍为 `sma5-20-cross-fixed100-v1`：20 会话热身、严格关系交叉、100 股、原限价/14 日有效期、下一会话 IOC、next-open 不利一分、固定容量 100。不会插入为了获得分红的 SMA 买单。7/6 起热身意味着 SMA 在登记前无仓；独立买入持有基准按首日收盘预定一次入场，在后续模型开盘成交，100 股实际经过同一分红 reducer。

登记在该日完整会话与 18:00 信号之后、19:00 冻结持仓；除息和支付只在显式事后模型开盘发生，先做公司行为，再做该日历史会话，最后才允许盘后信号。除息会释放旧挂单；不能把除息前信号换 ID 续用。盘后 OHLC 不用于判断早盘成交，历史 opening 也不构造 `OpeningEvidence`，不会进入 #10 forward gate。

共享 ledger 的唯一改动是允许**刚处理完同证券冻结 ex/payment 事件**的状态处于同一个开盘时刻，再进入原历史 next-open 路径；旧 v3 仍要求 `snapshot.as_of < opens_at`。没有改 Risk、分红金额算法、v4 事件/digest/checkpoint 或旧 v3 序列化。

现金分红遵循原 record→应收及税负→支付语义：

```text
NAV = cash + shares × unadjusted mark + gross receivable − modeled tax liability
NAV − initial = realized trading P&L + unrealized trading P&L + gross dividend − modeled tax
spendable cash = settled cash − buy reservations
external Owner flow = 0
```

支付把净应收换成现金，不再创造收益；应收不能资助买单。金融锁不因支付、日期或重启自动清除。人工手算例子中，100 股价格从 10.00 到 9.50、税前 42 元、模拟税 8.40 元，除息时总净值仍下降 **16.40 元**；不会机械报告“分红完全抵消，收益为零”。
