[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)核对日为 2026-11-03。Flash 每百万 tokens：缓存命中空闲/高峰 ¥0.02/0.04，未命中 ¥1/2，输出 ¥4/8。北京工作日（非法定假日）9–12、14–18 为高峰，其他为空闲。冻结版本 `deepseek-cny-20261103-peak-v1`；**所有输入按高峰、全 cache miss 预留**：

```text
Price 单位：micro_currency_1e-6，即 1 CNY = 1,000,000 micro
input_micro_per_million  = 2,000,000
output_micro_per_million = 8,000,000
最大预留 = ceil((32768 × 2000000 + 4096 × 8000000) / 1000000)
         = 98,304 micro CNY = ¥0.098304
```

这只是单次保守上界，不是 Owner 授权额度。Owner 的单次 hard cap 必须至少覆盖此界，原日/月剩余额度也必须足够。usage 估算同样采用峰值全 miss 上界，并单独记录 cache hit/miss 与 reasoning tokens；不把估算当真实账单。真实调用成功为 `usage_received`，**整笔 98,304 预留仍保留**，只有原 Owner 发票核销入口可结算。配置要求 Owner 给出价格核对时间和到期时间（跨度最多七日）；过期拒绝，价格变动需更新冻结费率/代码和新实验，不能静默套用旧价。

## 凭据、外发和失败边界

密钥来源只由本机配置提供，不把 Owner 的实际路径写入本文或证据。`configure/preflight/enable/status/history/report/verify` 不读取其正文。路径必须无链接，文件在 Git 外，或在 Git 内同时满足 untracked + ignored；tracked 明确拒绝，不改写 Git 历史。原文件从不覆盖。运行时只在具体请求已通过原预算和双重授权后读入 `Zeroizing` 秘密内存，不把密钥作为 argv、prompt、结果、日志或 hash 暴露。支持一个裸 Key、Markdown fenced Key 或 `API Key: ...`；多条、占位和其他凭据正文拒绝。对 Provider 原样或 JSON 转义反射密钥拒绝持久化，错误只保留静态原因。

真实请求与 recorded 不可互换：真实 Context 使用显式空 recording 标记且禁止出现 recording 文件；recorded 必须绑定录制 SHA，仍仅为 TST。真实 HTTPS 只能选固定模型/host，复用原安全客户端的公开 IP 检查、DNS pin、TLS 验证、无 proxy/redirect/retry。loopback 开关只编译在 Rust libtest 中；生产二进制没有替换传输的环境开关。libtest 的真实路径响应明确标 `LOOPBACK_NOT_REAL_PROVIDER`，不提高原模型验证状态。

首次外发的五个字段保持 allowlist：`response_source`、`research_boundary`、`development_summary`、`grammar`、`output_contract`。真实分支要求**精确等于代码生成的合成投影**：固定公开边界、零观测、无反馈、公开 grammar 和不含正文的技术来源 SHA。不会把 recorded 中的数据版本/日期窗口/开发反馈直接转为真实外发。真实行情行、因子/信号/派生统计、持仓/交易、路径和评价答案均不发送。本地历史计划和数据只供后续离线评价，不进入合成提示。未来真实派生摘要需要另行授权与许可审查，本版本不提供该开口。

原 AgentDir、authority_id、budget currency/timezone 和 `agent.sqlite` 始终是唯一费用权威；没有新钱包、币种兑换、补额或 Python HTTP。preflight 为只读，不调用 Agent 恢复或 DNS。最终 dispatch 重读最新配置和请求 SHA，原全局 pause 与实验 pause/cancel 都有效；一次开关与 dispatch 标记原子提交，重复 once 不创建第二个可能发送的请求。未发送的暂停可以按原安全重试入口显式恢复；不会自动重试 Provider。

可能发送后的超时、断开、429/5xx、重定向、无完整 usage、模型伪造或崩溃都保持原 `outcome_uncertain / OUTCOME_UNKNOWN` 与最大预留，跨日/月不释放。disable 只禁止后续 dispatch，已进入发送边界的请求可能已经计费。`Agent::open` 继续按原恢复规则处理 reserved/dispatched。核销复用：

```powershell
target/debug/stratided.exe --agent-settle '<EXISTING_CNY_AGENT>' <call-id> <actual-micro> '<OWNER_INVOICE_REFERENCE>'
```

只有取得真实费用依据的 Owner 使用该入口；不能用 0 猜测“未收费”。核销后原封存估算/研究 archive 不改签，verify 接受原账本合法的 usage_received → Owner invoice settled 转换，其他调用事实变更仍拒绝。

## Owner 操作

先构建（Windows 沿用已有 MSVC）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/with-msvc.ps1 build --locked -p stratide-research --bin structured-research-agent -p stratided --bin stratided
```

1. 选择**原来已经存在**、同一 Owner 的真实 CNY AgentDir；在其可信 `settings.json` 手动设定 daily/monthly hard cap 与原时区。不能拿 TST 目录直接换币种；本 CLI 不创建真实账本或改原额度。`default_model`、backup、原 fake/EOD 模型和旧任务不自动改变。
2. 将 [本机配置空模板](../research/agent/deepseek-owner-config.example.json) 复制到 ignored 本机目录，填 Key 文件绝对路径、Owner 单次 hard cap、明确批准时间、价格复核/到期时间；完成 DeepSeek 接收方、纯 synthetic 字段与 Provider 条款审查后，才将两个批准布尔值设为 true。模板的空值/false/0 会拒绝调用。本任务未替 Owner 填授权。
3. `configure` 只添加本模块 `ds4.1flash`，不选为全局默认，不启用网络；随后 `init` 冻结 PR15 本地实验。显式源根/版本沿用已冻结的 PR58/60，不复制/重新验证旧库；Owner 真正运行时才做一次既有 PR15 流式评价。

```powershell
python -I -B scripts/autonomous-research.py configure --out state/autonomous-research/<NEW_EXPERIMENT> --agent-dir '<EXISTING_CNY_AGENT>' --deepseek-config '<LOCAL_OWNER_CONFIG_JSON>'
python -I -B scripts/autonomous-research.py init --source authorized_cloud --agent-dir '<EXISTING_CNY_AGENT>' --v1-root '<V1_ROOT>' --v2-root '<V2_ROOT>' --v1-version <FROZEN_V1_VERSION> --v2-version <FROZEN_V2_VERSION> --out state/autonomous-research/<NEW_EXPERIMENT> --authorize-local
python -I -B scripts/autonomous-research.py preflight --out state/autonomous-research/<NEW_EXPERIMENT>
```

4. 检查脱敏字段说明、receiver/model/request SHA、实际 CNY 预算和最大预留，确认仅为合成提示；然后显式允许一个请求并运行 once。默认真实 source 模型是 `ds4.1flash`，无需改旧自动 EOD/fake 任务。

```powershell
python -I -B scripts/autonomous-research.py enable --out state/autonomous-research/<NEW_EXPERIMENT> --opt-in APPROVE_ONE_SYNTHETIC_DEEPSEEK_REQUEST
python -I -B scripts/autonomous-research.py once --out state/autonomous-research/<NEW_EXPERIMENT>
python -I -B scripts/autonomous-research.py disable --out state/autonomous-research/<NEW_EXPERIMENT>
```

5. `status/history/report/verify` 全部沿用原只读入口；无需密钥，也不恢复/结算费用或重新打开行情库。pause/resume/cancel 延续原本机研究控制，停止后不删除未知预留。

```powershell
python -I -B scripts/autonomous-research.py status --out state/autonomous-research/<NEW_EXPERIMENT>
python -I -B scripts/autonomous-research.py history --out state/autonomous-research/<NEW_EXPERIMENT>
python -I -B scripts/autonomous-research.py report --out state/autonomous-research/<NEW_EXPERIMENT>
python -I -B scripts/autonomous-research.py verify --out state/autonomous-research/<NEW_EXPERIMENT>
```
