## 使用许可与原始数据保留

用户协议 §二(三)限制账号本人使用；§五(一)(5)涉及未授权第三方软件使用限制。服务协议 §二(二)5 限定个人、非商业、不可转让、可撤销且有期限的使用，并限个人查看；§五(二)2 说明第三方数据的使用/收费问题由第三方解释。上述条款**没有明确覆盖 Stratide 自动化持久保存、前向 Paper 计算或私有 GitHub 原始样本保留**。这是本次核验的限制，不能解释为已获授权，也不能仅凭“不公开”推断云仓库存储被允许。官方 HTTP/MCP 文档说明存在程序化取得路径，但不消除具体使用范围问题。

因此，真实响应只可在确认许可后的受控本地运行目录保存；未经进一步确认，不向 GitHub 上传原始/标准化行情行、含行情的 CSV/JSON 或完整响应错误消息。PR 可留命令、状态、计数、经过检查的诊断与摘要哈希。哈希不能证明来源合规或远程原始数据可重分发。
