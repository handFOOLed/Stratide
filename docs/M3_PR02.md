## 数据和阶段

只读消费 #86 快照，不新增 Tushare 请求或权限。当前目录必须 `VERIFIED` 且分母已核验；不接收当日晚到回填/未来目录作为当日决策。连续 84 个交易会话由已记录的 SSE/SZSE 日历交集确认，每个会话的快照和实际接收时间必须在决策时点可用。缺上下文、坏质量或非 READY 时明确 BLOCKED，不借用旧 V1/V2 历史库补足本批次。

筛选规则冻结为 `market-screen-v1`：上市至少 180 个自然日，无上下文停牌，84 会话完整，复权因子无变化，连续昨收一致，OHLC/成交量有效，单日绝对涨跌不超过 30%，末日成交额 1,000 万至 1,000 亿元（源单位千元）。按末日成交额降序、代码升序打破并列，取最多 8 个。BSE 等上游不支持证券保留拒绝计数。规则参数、实现 SHA、完整证券池版本、所有拒绝、所选证券、特征时点、各会话快照 SHA 存入原 Agent DB。

本模块从**快照绑定的 native day versions**读取价格，不扩大 V1 历史查询截至 2026-10-30 的授权区间。复用原历史 CPU 适配合同和质量标签：因子不变仅表示未检出动作，不证明完整公司行为或历史 PIT。

阶段记录为 `EOD_RECEIVED → SCREENED → TIMESFM_DONE → FUSION_DONE/REJECTED → CANDIDATE_FROZEN`。阻断另显 `BLOCKED/CLOUD_RESEARCH_BLOCKED`，并保留已经达到的阶段事件。尚未入选时等待新 READY 源，入选后不重筛或混入新版本。跨进程 OS owner lock 只允许一个研究消费者；进程退出释放锁，恢复复用原任务和冻结输入。CPU 仍为串行、2 线程、batch size 1、6 GiB、无 swap、原 600 秒上限和断网隔离；部分失败不能进入云路径。

**R1 运行边界：** EOD 采集先持久完成，再进入可选研究阶段。研究/Agent DB、Worker、Registry 或子流程的异常只令当前输出的 `research` 标为 `BLOCKED / RESEARCH_UNAVAILABLE`；采集顶层结果、快照及原始请求 journal 保留，`watch` 继续原 30 秒轮询。Agent DB 不可写时，此故障只通过本机 CLI 的本轮 JSON 输出报告，不假称已持久写入 Agent；研究故障不证明本轮未发送或未计费，结果以原 Agent 记录为准。不输出异常原文，不重建 DB、不重置预算或重新发送未知付费请求。`KeyboardInterrupt/SystemExit` 仍能停止循环。此隔离针对异常，研究阶段仍按原有资源/超时约束同步运行，没有新增后台调度器。

**84 会话暖机限制：** #86 默认从配置日起采集，因此新安装不能立即产出市场策略。日历不足 84 会话时报 `MARKET_HISTORY_CONTEXT_UNAVAILABLE`，所需会话的快照缺失、非 READY 或尚未可用时报 `MARKET_HISTORY_NOT_READY_AT_DECISION`，研究均为 BLOCKED。继续正常累积即可；若 Owner 另行安排历史补录，须明确日期范围、可信来源和实际取得时点，补录数据仍只用于研究，不把它标为历史 PIT 或当时已观察；本次不实现历史补录器或放宽门禁。既有三证券 84 会话模型重放不等于全市场暖机完成。

**研究时点限制：** `source_day` 只表示行情所属交易日，`as_of` 是本批输入/筛选参考时点，不能证明最终候选当时已经生成；还须核对原任务的 `generated_at/finished_at`。跨日补跑 T 日数据应按 `LATE_RESEARCH_ONLY` 理解，不能当作 T 日或 T+1 开市前已经冻结的 Paper 决策。本 PR 未提供及时冻结/开市前准入认证，也未接入 #84；84 会话、同源日期或 `CANDIDATE_FROZEN` 状态都不能代替该时点证据。当前适配合同还可能因跨日 cutoff 不符而阻断，R1 不放宽它，不声称已实现所有延迟研究路径或自动 Paper 的时点门禁。

## 本机设置与运行

先按 [M2-PR18](M2_PR18.md) 使用已安装的 Linux/WSL2 `systemd-cgroup-v2+bubblewrap` CPU 环境、官方权重和 venv。在该工程构建新二进制，保持原 Agent 绑定；Windows 原生生产推理未新增实现。Dashboard 复用原 attach 模式，不另起占用同一 `agent.lock` 的后台研究实例。

```text
cargo build --locked -p stratide-research --bins -p stratided
python -B scripts/market-research.py status
python -B scripts/market-research.py install-model
```

`install-model` 仅复用已有本机 DeepSeek key/价格配置，添加新模型协议；不读取 key 正文，不修改旧模型/默认模型，不提高日/月预算或复制历史许可。既有价格配置过期时按原流程刷新配置，不猜测费率。新模型固定 `deepseek-flash` / `DeepSeek-V4.1-Flash-1017_ALIAS_MUTABLE`，Provider 别名可变这一限制写入收据。

解锁本机 Owner 控制，在“设置 → 安全”保存两个自动开关、候选数、上海时区每日调用数和每源交易日调用数。每日/每交易日调用数允许 1–8；流水线当前每源日仅创建一个批次和一个云任务，较高配置不构成重复调用许可。CLI 等价配置：

```json
{
  "automatic_timesfm": true,
  "automatic_deepseek": false,
  "candidate_count": 8,
  "daily_call_limit": 1,
  "trading_day_call_limit": 1,
  "model_version": "DeepSeek-V4.1-Flash-1017_ALIAS_MUTABLE"
}
```

保存到本机文件后：

```text
python -B scripts/market-research.py configure --input research-config.json
python -B scripts/eod-operator.py market once
# 或继续使用原来的前台循环；没有第二个 watch/服务/预算库
python -B scripts/eod-operator.py market watch
python -B scripts/market-research.py preview --day YYYYMMDD
python -B scripts/market-research.py pause
python -B scripts/market-research.py revoke
```

市场采集仍由原开关/正式窗口控制，本期未替 Owner 启用采集或自动化。若需要仅消费已发布源，可显式 `python -B scripts/market-research.py once`。配置变更应用于后续批次；暂停和撤销在当前任务发送前再次校验，阻断未来调用。正在进行的本地推理可以完成，已发送请求不能撤回。

## 外发与预算

真实外发许可是**独立**的本机 Owner 操作：逐项选择 DeepSeek 接收地址、`market_strategy_research` 用途、`tushare_market_eod` 来源类别、7 个允许字段、最大证券数、84 会话上下文/20 会话预测、明确到期时间，并确认 Provider/来源条款。确认复选框和全部字段均不预选。

允许字段只有 `symbols/risk_forecasts/baselines/source_refs/quality/as_of/output_contract`。发送投影不接受自由文本来源对象、原始行情、持仓、账户余额、账本、key 或文件路径。缺一个字段、错用途/接收方/来源、超范围、过期、撤销均拒绝。原 synthetic/recorded 模型及其许可不授权此协议，生产入口也不接受 synthetic MarketDaySnapshot。libtest 的 synthetic 源只能走测试专用 loopback，收据明确 `TEST_LOOPBACK_NOT_REAL_PROVIDER`。

许可版本、授权时刻、范围与 SHA 追加保存在原 `agent.sqlite.meta`，撤销保留版本和时间。输入/调用收据冻结许可、模型、父任务、源、Prompt、请求和结果 SHA；模型返回的权重必须守恒、证券必须来自本批次，受控结论不能由自由文本改写。定量假说保留在 `UNTRUSTED_HYPOTHESIS`，不进入交易、预算或资格决策。

本机预览可在尚未授予真实外发许可时读取真实派生 payload 和最坏费用；不运行模型、不读取 key、不发送请求。没有可用父结果时显示明确阻断，不填示例冒充实际内容。已有 Provider 模型配置是预览前提。预算始终使用原原子预留与派发复核，CNY 日不高于 ¥5、月不高于 ¥100，上海时区。未知结果跨日继续保留最大预留，不自动重发、不自动结算。

网页读取仅 GET。写入复用 `X-Stratide-Owner`、同源与 JSON 边界，且必须匹配原 Agent binding。设置内显示进度、全市场筛选数量/拒绝计数、冻结组合/假说/收据和费用；阻断写入原非派发状态任务，进入既有通知箱，不伪造模型完成。

已核对官方 [Tushare daily](https://tushare.pro/wctapi/documents/27.md)、[复权因子](https://tushare.pro/wctapi/documents/28.md)和 [DeepSeek 隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)。日线未复权、成交量为手、成交额为千元。Provider 会处理已发送内容；撤销本机许可不承诺删除接收方已取得记录。来源再分发资格仍须 Owner 针对实际账户核对，不因安装 Skill 或本 PR 自动取得。
