## 1. 一句话产品定位

Stratide 是一个只在本机运行的模拟盘：盘后用 Tushare 数据更新行情，经过交易保护后
按次日开盘价模拟成交，并把 AI 研究报告作为决策参考保存下来。它不连接券商、不下真实
订单，也不承诺收益。

## 3. 允许保留的专有名词

Tushare、DeepSeek、OpenAI、API Key、WSL、Windows、¥、日期与数字。除此之外的英文
单词（Agent、Owner、Supervisor、EOD、PIT、Paper、token、micro、hash 等）只能出现在
“诊断信息”折叠区或本术语表。

## 4. 统一状态体系（只有 5 种）

| 状态 | 颜色 | 图标 | 使用场景 | 必须附带 |
| --- | --- | --- | --- | --- |
| 正常 | 绿 | 对勾 | 服务在线、数据正常、任务完成、交易保护无触发 | 一句话现状 |
| 进行中 | 蓝 | 活动脉冲 | 排队中、运行中、正在采集/补录 | 进度或“等待中”说明 |
| 需要处理 | 橙 | 警告三角 | 未配置、暂停、预算耗尽、部分依赖缺失、结果未确认 | 处理入口（按钮或链接到设置） |
| 出错 | 红 | 八角警告 | 服务断开、运行失败、数据读取失败 | 一句话原因 + 重试/去设置 |
| 未设置 | 灰 | 信息圆点 | 未选择数据、未开始、已取消、已跳过 | 下一步提示 |

规则：

1. 徽标必须同时有图标 + 颜色 + 文字，不能只靠颜色区分。
2. 不直接渲染后端枚举值；未知枚举显示“状态未知”，原始值只进诊断信息。
3. 同一状态词全站一致：不要出现“已配置/已安装/可用/在线”等并行说法。
4. 失败必须写一句话原因；确实拿不到时写“失败，原因未记录”，并在诊断信息保留原始字段。

## 5. 数字、金额、时间、数量

- 金额：¥ + 千分位 + 两位小数（例：¥9,928.93）。不使用 CNY、RMB、“元”。
- 百分比：两位小数 + %，收益带 +/−。
- 数量：`formatCount` + 单位（笔、只、条、个、天），不混用“0 条 / 共 0 笔 / 0 只”。
- 日期：`YYYY-MM-DD`；时间：`YYYY-MM-DD HH:mm`，全部按 Asia/Shanghai。
- “更新于”只用于本机读取时间；“数据日期”只用于行情/账本数据本身的日期。

## 6. 诊断信息折叠区

技术信息不删除，只下沉：默认收起，标题固定为“诊断信息”，内容以键值对或原始 JSON
展示，并提供“复制诊断信息”按钮。包含但不限于：内部 ID、后端枚举、hash、版本串、
数据模式、证据等级、PIT/时点说明、快照 ID、账本头、模型 key、调用记录、日志。
