# Troubleshooting · 问题排查

[← 文档](README.md) · [使用指南](USER_GUIDE.md) · [Windows 安装](WINDOWS_INSTALL.md)

先从 **设置 → 运行与安装** 查看服务、数据与 Worker 状态，再按照对应问题排查。

| 现象 | 可能原因 | 建议 |
| :--- | :--- | :--- |
| Dashboard 打不开 | 服务未启动、端口占用或 Launcher 出错 | 用桌面图标重试；检查本地日志与端口 |
| 行情没有更新 | Token、Tushare 接口权限、交易日/数据质量 | 查看 EOD 来源日期和后台状态 |
| TimesFM 不运行 | WSL2、venv 或模型缺失 | 保存桥接配置并执行 Worker 检测 |
| 没有自动研究结果 | 84 个合格会话不足、权限/模型/预算不满足 | 查看 AI 研究页具体阻断信息 |
| DeepSeek 不调用 | API Key、许可、配置或费用限制 | 检查设置；未知费用任务不应强行重发 |
| 模拟账户没有成交 | 规则、仓位、资金、时点或次日行情不足 | 查看交易记录与拒绝原因，允许 `NO_FILL` |
| 预算修改成功但研究停跑 | UI 可编辑预算，市场模型仍有既定硬上限 | 当前市场研究保持不高于 **¥5/日、¥100/月** |

## 运行前提

- **Windows 11 x64** 是当前目标平台；TimesFM CPU 需要现有 WSL2/ext4 和模型权重。
- 新安装的研究数据可能尚未满足 **连续 84 个 READY 交易日快照**要求。行情采集可先独立运行。
- 源数据覆盖全市场不等于全部证券均可进入研究，更不等于所有证券都有可成交的 Paper 假设。当前自动 Paper 的适用证券和额度受预设政策限制。
- 本地服务监听 `127.0.0.1`。请避免将程序和唯一正式数据账本放在卸载时可能被整体删除的同一自定义目录。
- 安装包未签名，Windows 可能有 SmartScreen 警告；仅从可信发布渠道获取并核对实际文件哈希。

## 云端研究与模拟成交

- 使用者在首次协议中确认接收方、目的和摘要范围后，才允许相应真实数据派生摘要用于云研究；上传的**不是**原始行情文件或账本。仍应在设置中正确配置服务提供方。
- 研究预算是 Stratide 内部的限制，不覆盖同一个 API Key 在其他软件产生的费用。未确认的 Provider 账单不会被简单视为零费用或盲目重复请求。
- **Paper-only**：不连接真实券商。T 日盘后冻结意图，T+1 盘后取得开盘日线后记录 `EX_POST_OPEN_ASSUMPTION` / `NO_FILL`，不是实际市场成交。
- 公司行为与历史 PIT 证据不充分时应保留“未验证”的标签；模拟或回测表现不证明未来收益。
