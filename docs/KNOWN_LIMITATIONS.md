# Stratide 故障排查与已知限制

> 此页是进阶参考，不是 GitHub 首页的产品介绍。它记录了当前实现条件、故障解释和开发阶段验证边界，避免把软件“可安装使用”与“每项真实市场结果都已独立证实”混为一谈。使用入口见 [使用教程](USER_GUIDE.md)。

## 环境与安装

- 当前目标环境为 **Windows 11 x64**；安装包带本地服务、静态 Dashboard 和 CPython，日常运行不要求自行构建。
- TimesFM 2.5 CPU 权重与已有 WSL2/ext4 venv 需要自行准备；安装器不会附带或自动下载大模型。WSL/Worker 不可用时研究 `BLOCKED`，EOD 采集仍可正常工作。
- 安装器没有代码签名，Windows SmartScreen 可能显示来源提醒。建议从项目 Release 获取并核对对应 SHA256。
- 用户自定义程序与数据目录建议保持默认**分离**。极端重叠/重解析路径和其他本机进程伪造服务响应的风险在 #89 Owner 定义的个人自用范围内没有额外加固；不应误写成已经消除。不要把唯一正式账本置于打算整体删除的程序目录中。
- 本地服务监听 `127.0.0.1`；不是 LAN/公网服务。登录自启是当前用户级机制，不是常驻系统管理员服务。

## 数据、研究与模拟交易

- 全市场 **EOD 采集覆盖**、**进入研究的证券子集**、**Paper 实际支持的撮合证券**是不同概念。筛选、行情、停牌和权限都有独立门禁。当前 Paper 自动假设撮合仅支持满足保守条件的普通成熟沪深主板证券；不代表所有 A 股都可成交。
- 本地 TimesFM 需要 **84 个连续合格（READY）交易日快照**作为上下文。新装仅从配置日开始采集时，暂时无法立即自动产出策略是预期行为。
- 真实行情或其派生摘要默认不得外发 DeepSeek；需要独立 Owner 许可，且可以撤销。统一 Agent 的 **CNY ¥5/日、¥100/月**是软件内部预算，不限制同一 API Key 在其他应用中的花费。预留/估算/实际账单并不必然相等，未知费用不能盲目重发。
- Paper-only，不接券商或真实资金。模拟成交按 **`EX_POST_OPEN_ASSUMPTION`**：T 日盘后固定决策，T+1 盘后取得日线后用其开盘价作回放假设；没有实际在 T+1 开盘时观测或报单。公司行为未核验的保守假设需 Owner 独立选择，输出仍明确标注 `UNVERIFIED`。
- 研究输出和历史回放不证明策略有统计优势，历史 PIT、公司行为、可成交性和独立真实前向评测需另行验证。长期全市场自动真实 EOD→DeepSeek→Paper 的现场运行效果不能仅由开发期合成测试证明。

## 原 PR #89 的验证边界

[PR #89](https://github.com/handFOOLed/Stratide/pull/89) 在 R2 审查后合并：Windows 安装外壳与 WSL2 TimesFM 自动桥接已进入 main。开发者报告真实 WSL2 模型 CPU 推理、安装态 payload 复跑、相关 E2E/故障回归通过。原开发沙箱里**未实际完成**的项目包括普通桌面会话的真实安装快捷方式/登录自启/卸载、浏览器唤起、系统重启/唤醒、真实 Tushare 全市场与付费 DeepSeek/Paper 全链路。记录中保留 `NOT_RUN` 是工程证据状态，不表示当前软件不可打开使用。

## 常见问题

| 现象 | 首先检查 | 推荐操作 |
| --- | --- | --- |
| 无法打开 Dashboard | 服务健康、端口 8710 或自定义端口 | 用桌面快捷方式重新启动；检查“最近后台日志” |
| 显示 `EOD_NOT_CONFIGURED` | 未创建 EOD 仓库 | 设置 → 运行与安装 → 输入日期 → 初始化/启用 |
| 行情停滞或覆盖不足 | 数据许可、交易日、日线和停复牌证据 | 查看质量/权限标签；不要手动把 PARTIAL 改成 READY |
| `TIMESFM_WSL_*` | 发行版名称、WSL 工作树、模型和 venv | 在「WSL2 TimesFM 桥接」保存配置并点击检测 |
| `MARKET_HISTORY_CONTEXT_UNAVAILABLE` | 合格交易日上下文不足 | 继续积累 READY 快照；不要用测试数据补齐真实研究 |
| 研究不调用 DeepSeek | 自动研究开关、授权、预算和任务状态 | 到权限与安全页检查许可；不要重复发送未知费用任务 |
| Paper 空仓或 `NO_FILL` | Paper 账户、Policy、来源时点、资金、交易限制 | 查看拒单/批次状态；不要绕过原 Risk→Ledger |
| 停止/重启后没有研究 | 当日任务幂等及冷却、未知请求结果 | 看持久任务与日志；等待合理窗口，不删库强行重跑 |
| 无法卸载 | Windows 用户权限、正在运行的后台 | 先从开始菜单停止后台；保留并备份原用户数据 |

开发和构建故障另见 [Windows 安装手册](WINDOWS_INSTALL.md)、[历史模块/项目进度](STATUS.md)。
